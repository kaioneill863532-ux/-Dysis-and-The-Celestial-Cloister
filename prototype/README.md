# 原型

## v0.4 神殿灰盒（`temple/index.html`）

按 v0.4 方案重搭的灰盒：从北边海上的小岛沿光走上台地，直走到神殿北门；白天顺时针一层层往上，从圆眼上到屋顶接住最后一缕阳光；入夜后逆时针一层层往下，把金苹果放上水亭的浑天仪。用较新的桌面版 Chrome、Edge 或 Safari 直接打开就能玩（需要联网加载 Three.js 和字体）。

建筑的比例、每一扇窗、每一根柱子、楼板和栏杆的缺口、墙里的楼梯、雕像的朝向，都在启动时按日月轨道解算出来，所以光路一定落在该落的地方。所有尺寸和角度见 [UE 数据册](../docs/ue-spec.html)。

| 关卡 | 位置 | 要做的事 |
|---|---|---|
| 序 · 登殿 | 小岛 → 台地 → 北门 | 岛上时间不动。沿海峡上的光走上台地，走进北门 |
| 日1 · 午后·水庭 | 水庭 → L1 | 子午线的圆斑随脚步滑动。B1 的光脚在东北，走上去到 L1 |
| 日2 · 未时·柱廊 | L1 → L2 | 在 L1 顺时针走到北侧。B2 被帕拉第奥母题的柱子切开，只有穿过中间宽拱时完整 |
| 日3 · 申时·光阶 | L2 → L3 | 走上 P，跳到旁边低一点的 R，上到 L3。支路：站上托镜像的圆台，转到对的格子，镜光通到东墙的日之龛 |
| 日4 · 酉时·圆眼 | L3 → 屋顶 | 光圈一片片张开。圆眼光柱落到 L3 东北时沿半径往里走，走在光的上表面 |
| 日5 · 日落·最后一缕 | 屋顶 | 朝太阳走到环道，顺时针上台阶。背对夕阳，虹填满拱门；取下浑天仪上的金苹果 |
| 月1 · 月升·读墙 | 屋顶 → L3 | 逆时针往回走。东南的楼梯下半段是月石，月门竖棂的影子让开时整段显出 |
| 月2 · 初夜·天鹅 | L3 → L2 | 月光下女神像变成天鹅。转到对的方向，影子补进浮雕的空白，墙里的楼梯打开 |
| 月3 · 中夜·双子 | L2 → L1 | 托镜像把月光反射进龛里。两尊像同时亮就合成跨过断口的桥 |
| 月4 · 夜半·沉光 | L1 → 水庭 | 光圈照下的月光沉到 L1 西墙，照出月石门（旁边是月之龛） |
| 月5 · 子夜·水亭 | 水庭 → 水亭 | 转岸边的托镜像，让两段半桥同时亮，走到水亭，把金苹果放上月托 |

操作：WASD 移动，鼠标视角，Shift 快走，空格跳，E 互动，T 等时线，V 切换视角，H 说明，M 静音，R 回到上一个落脚点。

镜子反射的光现在很好走：镜子 2.6 × 1.6 m，下沿和圆台顶一样高，反射出来的是 6° 的缓坡；站上圆台以后时间不动，光不摆；可踩宽 3.3 m，镜子后面还多铺 0.6 m。

还没做：伊莉丝浮雕、虹桥、虹之龛、棱镜和塞勒涅浮雕这条支线；柱影钟的表盘；水面波光。

## 旧版：日月十关（`cloister/index.html`）

这是一个可以完整通关的灰盒原型，用浏览器里的 Three.js 做成。白天从正午的水庭一路走到日落的塔顶；入夜后，再从塔顶走回水庭中心的小亭。

整个原型只有一个 HTML 文件，用较新的桌面版 Chrome、Edge 或 Safari 直接打开就能玩（需要联网加载 Three.js 和字体）。手机上也能打开，用触屏摇杆和跳跃键操作。

关卡不按楼层分，同一层可以放好几关。日时五关、月时五关，中间是日月回廊。塔身还是原来的四层加屋顶。

### 流程

| 关卡 | 位置 | 要做的事 |
|---|---|---|
| 日1 · 正午·起雾 | L0 → L1 | 从干潮沟里走出来，跟着水面上的光斑走到水闸旁，打开水闸。水雾让光显形，踩着光路登上 L1 的高窗 |
| 日2 · 午后·双窗 | L1 → L2 | 顺时针走到北侧，从下窗的光爬上 L2。拉杆让石板改挡下窗，打开狮首水闸，让雾升到塔顶 |
| 日3 · 申时·三相 | L2 | 转动托镜石像的底座，让她面向高窗。她被阳光照醒，举起镜子，第五格把光送到 L3 东南 |
| 日4 · 酉时·光阶 | L3 东南 → L3 西 | 南墙三扇高窗射进三束平行的光。从第一束跳到第二束，走到它的窗台，进入 L3 西段 |
| 日5 · 日落·最后一缕 | L3 西 → 顶层 | 穿过甲门，沿绕塔坡道上顶层。顺时针走，天花板像光圈一样收起，前方半圈升成阶梯；在最高一级举起金苹果，回头看虹填满虹门 |
| 日月回廊 · 日落之后 | 顶层 → L3 | 入夜后逆时针才是向前。阶梯落平，另外半圈降成阶梯，通到 L3 |
| 月1 · 月升·天池 | L3 | 进水口开着，水面起波纹。面向刚出海的月亮，踩着月光大道走过天池（也可以关掉进水口，踩月光踏片）。到东边的竖井，站上井里的月光，拉铜链 |
| 月2 · 初夜·借月 | L2 | 铜链被刹杆卡住。把托镜石像转向东边，月窗的光照醒她，她把镜子递出去。再转一格，月光落在竖井门框的银月上，刹杆松开，降到 L1 |
| 月3 · 中夜·环渠 | L1 | 沿 L1 逆时针绕一整圈。在石格窗投下的月光里走过环渠，打开闸轮，回到竖井再拉一次铜链 |
| 月4 · 夜半·潮 | L0 | 关掉日1 打开的水闸。开场时的干潮沟已被海水灌满，捧着金苹果走近沟里的夜光石，趁它们亮着一块块踩过去 |
| 月5 · 子夜·归亭 | L0 | 子夜前后，面向南方的月亮走过水面，把金苹果放进小亭的铜碗 |

### 可选：三个时辰龛

都不挡主线，错过了也能通关。收集进度显示在屏幕上（时辰龛 n/3）。

| 时辰龛 | 在哪里 | 怎么拿 |
|---|---|---|
| 日之龛 | 日4，光阶第三束光的窗里 | 从第二束光再跳一次 |
| 虹之龛 | 日3，L2 虹窗下的窗台 | 见下文"彩虹链" |
| 月之龛 | 月5，去小岛路边的井台井底 | 子夜时井底浮着一轮月亮，跳下去；拿到碎片后，潮水把人托上来 |

**彩虹链**：

1. L2 竖井朝中庭的一面有一块伊里斯浮雕，刻着一整圈虹，圈中间空着一个描金边的人形。
2. 转动虹台上的轮子，打开对面墙上的虹窗，阳光照进浮雕前的水帘。
3. 背对太阳，让自己影子的头落进那个人形。看到的彩虹和刻的虹重合，浮雕里的虹醒过来，变成一座虹桥。
4. 走过虹桥，到窗台上的虹之龛，拿到彩虹碎片。
5. 窗台随即伸出一块石板，上面立着一块水晶棱镜。转动棱镜，把七色光投到北墙另一块浮雕上。
6. 靛色落在塞勒涅的眼睛上时，众神开始对话。

在拿到碎片之前去碰这两块浮雕，都会给出提示。

### 实现要点

- **天象**：
  - 太阳沿一条固定的倾斜圆轨道运行，最高约 34°。
  - 满月在太阳的正对面，走同一种圆轨道（赤纬 +20°），子夜升到约 75°。
  - 日落后，星空绕北天极转动。
- **每层一段时间**：
  - 各层各有一条单调平滑的"方位角 → 时刻"曲线。每条曲线的接缝放在回廊断口、实体墙或竖井处。
  - 从一层踏上另一层的地方，两边的时间取相同的值。
  - 入夜后换成另一组曲线，时间随逆时针增加。两组曲线在接光台处相等。
- **水钟**：夜里竖井里的时间由水位决定，每放一层水，时间往前走一截。从 L3 放到 L2，月亮正好升过柱廊檐口，井里的月光才照得到水面。
- **顶层环道**：
  - 环道分成 32 级踏步，每级带一片光圈叶片。
  - 顺时针走时，前方 16 级按走过的角度逐渐升起，叶片外收。
  - 入夜后逆时针走，另外 16 级逐渐降下，最低一级落在 L3。
  - 每一级的高差不超过一步，站着的那一级会被慢慢托起。
- **光路**：
  - 在每扇窗的内侧取样，向太阳发射线。墙厚、窗框、柱子、滑板和岛影都会挡光，得到真实的受光截面。
  - 再沿光线方向求出四个角的落点，光束的下表面就是可以行走的面。
  - 铜镜按反射定律把光再射出去。
  - 站在光路上时，光路随时间摆动，会带着人一起走。
- **光路的宽容度**：
  - 判定宽度两边各多出 0.3 米。
  - 站在光上时，坡度上限放宽到 38°，雾浓度门槛也会降低。
  - 光路两侧有一道软护栏，只拦横向的滑出；下方 6.2 米内有地面时不拦，方便从光路走下来。
  - 离开光路后 0.14 秒内仍然可以起跳。
- **跳跃**：起跳速度 7.6 m/s，重力 22 m/s²，大约能跳 1.3 米高；走着跳约 2 米远，快走跳约 3.5 米远。回廊的栏杆跳起来也翻不过去。
- **三相像**：
  - 托镜石像有三个姿态：站在阳光里、面向太阳时举镜，这是唯一会反射的姿态；背对光时垂镜；面向月光时递镜。
  - 姿态随光线平滑过渡。
- **月光**：夜里，水面上只有亮着的东西才能踩。
  - **月光踏片**：水面分成约 1 米的踏片。一片踏片亮，要同时满足三条：水面平静；这片水被月光直接照到（用射线检测窗口，或按几何计算开口和楼板）；视线朝着月亮（相差不到 80°）。脚下那一片一直保留，直到离开它。
  - **月光大道**：起波纹的水面上，从脚下朝月亮方位每 0.3 米铺一步，只铺在有月光的水面上。站在上面时会一直保留。
  - **夜光石**：被金苹果照亮后可以踩，约 14 秒后慢慢暗下去。
  - **井中月**：井半径 0.9 米、深 2.4 米，月亮高过约 69° 才照得到井底。
- **彩虹与棱镜**：
  - 虹窗的位置和高度，是按浮雕那一刻的太阳方向和 42° 的虹角反推出来的。
  - 棱镜用斯涅尔定律逐色计算出射方向：顶角 45°，折射率从红 1.600 到紫 1.642。
  - 判定"落在眼睛上的是哪种颜色"，取离眼睛最近的那一道。
- **岛影**：
  - 西边海上有一座岩岛，朝塔的一段山脊是平直的。
  - 一块看不见的挡板放进阴影计算里，它的上沿和山脊在同一个阴影边界面上。所以塔上的影子、窗口的受光和岛的轮廓三者一致。
  - 顶层的时间曲线调成岛影一路追在人脚下。
- **体积光与彩虹**：
  - 场景先渲染到带深度的离屏目标，再在全屏合成里对光束做光线步进。
  - 散射用 Henyey–Greenstein 相位函数，并按光学厚度做饱和。
  - 彩虹按真实角度计算（主虹 40.6°–42.3°，副虹 50.3°–53.4°）。
- **接光台与虹门**：
  - 接光的时刻，正好是岛影漫过放在架上的苹果、还没漫到举起来的苹果的时刻。
  - 虹门跨在下一级踏步上，大小按"从接光台看去 42°"计算，日落时虹正好填满拱门。
- **性能**：
  - 大圆环切成 15° 一段，每扇窗只测附近的遮挡物。
  - 月光踏片只在月亮挪动、水位变化、而且人在附近时才重算。

### 验证

我用 Playwright 在无头 Chromium 里做了测试：

- **完整通关**：用脚本模拟按键，从出生点一路走到小亭，途中包括光阶的跳跃、借月、潮沟和夜光石。检查了每一次换层时时间是否接得上。
- **可选内容**：三个时辰龛和彩虹链（直到靛色照到塞勒涅的眼睛）各单独跑通。
- **反向检查**：
  - 进水口关着、背对月亮时，天池不亮。
  - 银月没被照亮时，铜链拉不动。
  - 水闸开着时，水庭不亮。
  - 月亮不够高时，放不下苹果，井底也不亮。
- **扫查捷径**：把各层各时刻的光路扫了一遍，没有发现能跳过谜题的捷径。
- **截图检查**：光圈天顶、日落虹门、浮雕和虹桥、棱镜色散、月光大道、夜光石、井中月等画面。

真机上的帧率、手感和声音还需要实际试玩。

### 灰盒说明

尺寸、位置和时间曲线都是为了验证手感临时定的。以下内容还没有做：

- 夜里用双窗滑板让子夜的高月从高窗照进来的联动
