# 原型

## v0.9 神殿灰盒（`temple/index.html`）

在 v0.8 上按第四轮试玩反馈改了这些，关卡流程不变（见下面 v0.8 的表）。

- 伊莉丝浮雕照不出影子：v0.8 里浮雕正好放在南窗那块亮斑的下沿上，人形被切在暗处，影子落进去也看不见。这一版把"虹的窗"开大（宽 4.0 m、高 4.2 m，窗台在三层楼面以上 2.3 m），浮雕按"亮斑整个罩住浮雕"重新定位（二层东墙 76°，约 94% 的浮雕面照得到，剩下的是浮雕自己的边框），对准的容差从 0.22 m 放宽到 0.34 m。站对的地方从一个 25 cm 的点变成约 0.5 × 0.7 m 的一块。虹之龛挪到窗台西头（窗洞外面的墙上）。
- 通向日之龛的镜光：三相像台子四周的看不见的高护栏只在镜光越过的那一段拿掉，从台子上走不进中庭；镜光中段两边一直拦着（只有起头 1.5 m 和落到石台前 2.5 m 能走下去），走歪了也不会掉；日之龛的石台加宽到 17°，比镜光还宽。从台子上沿光往东走、偏左偏右 1 m、方向歪 3° 都能走到石台上。
- 夜里光圈一直全收着，整片天幕都开着（不再合成月眼）。天鹅像因此早亮一些：人在四层走到 347° 左右就看见她亮了（原来要走到 288° 左右），离她还有大半段路；解天鹅的那一刻（站到她跟前）不变，后面的机关都在光圈本来就全开以后，不受影响。
- 虹桥入夜以后整座消失（踩不了），夜里的场景干净些；月桥白天完全看不见（原来留着一道很淡的轮廓）。
- 删掉了环道内沿那一圈铜边（楼梯降下来以后它一整圈悬在半空）。
- 墙的外形：
  - 拱窗的拱头原来是三条越来越窄的横条叠出来的（锯齿），现在墙上挖一个整宽的矩形，两个上角补上贴着圆弧、穿过整个墙厚、跟着窗洞斜切的拱肩，拱是光滑的；拱顶不碰上一层的楼板。
  - 四层南墙上开场的窗和光阶第二、三束的窗叠在一起，挖出来的洞很乱；这三扇合成一扇 6 m 宽的大拱窗（光束还是按各自的窗算）。
  - 外立面上：主光窗的拱圈按外墙面上洞口真正的位置和宽度贴（斜切的窗洞在外面是挪开的）；壁柱、盲拱碰到真的窗洞就不贴。
  - 墙里楼梯朝外的窗对准外立面开间的中线，开在那一间的盲拱里，外面看就是这一间的小窗（上面的楼梯 3 扇、下面的 2 扇）。

## v0.8 神殿灰盒（`temple-v0.8/index.html`）

层高和外形沿用 v0.5–v0.7。这一版按第三轮试玩反馈改。楼层叫法：一层是水庭，往上是二层、三层、四层，再往上是屋顶（代码里分别是 L0–L3）。用较新的桌面版 Chrome、Edge 或 Safari 直接打开就能玩（需要联网加载 Three.js 和字体）。

| 关卡 | 位置 | 要做的事 |
|---|---|---|
| 序 · 登殿 | 小岛 → 台地 → 北门 | 开局站在岛的外沿，岛上没有光。往神殿走一步，太阳转过来（时间从 H_I − 4.5 走到 H_I），光穿过殿堂落到岛上；沿着它走上崖边，进北门 |
| 日1 · 午后·开闸 | 一层 → 二层 | 顺时针走到东边瀑布前的水闸石台，打开水闸。瀑布脚下的水沫顺着水面飘到第一束光的光脚上：从水闸往回走（背对太阳）时，光脚上立着一段虹。沿着这束光爬上二层 |
| 日2 · 未时·双窗 | 二层 → 三层 | 拉下二层西南的机关 A：西窗开、南窗关，沿西窗的光上三层。支线：伊莉丝浮雕在二层东墙，机关 B 就在浮雕旁边（拉过 A 再来，浮雕是暗的，会提示旁边的机关）。影子的头落进人形，虹醒过来，一道彩虹桥拱过中庭；南窗下的墙里这时才伸出窗台接住它，窗台右手露出虹之龛。开龛、升棱镜、靛色落进塞勒涅的眼睛 |
| 日3 · 申时·光阶 | 三层 → 四层 | 光阶照旧。支线：三相像的镜光越过中庭，通到三层东边外墙上挑出来的石台（96°，在四层楼板底下），石台上是日之龛；从石台两头走下去落回三层，或者顺着镜光走回去 |
| 日4 · 酉时·圆眼 | 四层 → 屋顶 | 同 v0.7 |
| 日5 · 日落·最后一缕 | 屋顶 | 同 v0.7 |
| 月1 · 月升·回廊 | 屋顶 → 四层 | 另外半圈降成楼梯落到四层东边。楼梯整夜都留着，想回屋顶随时能走上去；楼梯那一段的光圈叶片留在天花板的圈上，月眼照常合拢 |
| 月2 · 初夜·天鹅 | 四层 → 三层 | 同 v0.7 |
| 月3 · 中夜·三相 | 三层 → 二层 | 同 v0.7；月之龛就在三相像扫过的三层北墙上 |
| 月4 · 夜半·双子 | 二层 → 一层 | 同 v0.7 |
| 月5 · 子夜·瀑布后的女神 | 一层 → 水亭 | 镜子反射的月光打到瀑布上，那一块水帘透开，照见后面胸口左侧抱着一轮月亮的巨像。走月桥下来时光从她怀里的月亮上扫过去，只亮一下；掉头走回月桥（离落地约 5.7 m），站在月光整个罩住那轮月亮的地方约 1 秒，她亮起来，水池东北边的池沿伸出一段半桥。沿水庭逆时针走到半桥上，屋顶细桥的月影落在水面上，从半桥尽头接到水亭：影桥。把金苹果放上浑天仪。不用关水闸 |

和 v0.7 相比：

- 开场：岛上的时间不再固定。站在岛的外沿是 H_I − 4.5，南窗还没对准海窗，岛上没有光；往神殿走约 1.5 m，时间走到 H_I，光才穿过殿堂落到岛上。
- 一层的虹：太阳在西南偏南（方位约 205°、高约 30°），虹总在背对太阳的方向（离对日点 42°）。往上走光路时是朝着太阳走，虹在身后；唯一背对太阳的一段路，是开闸以后从水闸往回走向光脚。这一版让瀑布脚下的水沫顺着水面飘到光脚（92°–116°，离池岸 8–13 m，4 m 以下），于是往回走时，光脚上正好立着一段虹（主虹和淡淡的副虹）。
- 机关 B 从二层南边移到伊莉丝浮雕旁边（浮雕北侧 8°，影子不落到浮雕上）。v0.7 里照不出影子，多半是先拉了机关 A，南窗被石板挡上了；水流不挡这束光。
- 日之龛从瀑布里面移到三层东边外墙（96°，比三层高 5.5 m，在四层楼板底下），镜光自动重新对准。石台两头不设挡头，走下去落回三层（5.5 m，不会摔回重生点）；石台不算落脚点，从正面掉进中庭会回到三层。
- 四层在瀑布和光阶断口之间那一段孤立的回廊（140°–156°）拆掉了，从镜光上跳不上去了。
- 夜里下来以后楼梯不再收回。拿同一夜的月光比对过：楼梯留着时屋顶那一段开着口，只会让三相像的镜子早一点照到月亮、卡斯托耳早一点亮，都在玩家到不了的时刻，所有机关触发的时刻不变。
- 墙里的楼梯（1 m 宽）换了镜头：进去以后不偏肩，瞄点收到楼梯中线，五条射线一起探，最远 2.6 m。1296 个姿势测下来没有一个穿进墙里（v0.7 是 538 个）。水流着的时候整根水柱也挡镜头，站在水闸边镜头不会钻进瀑布。
- 窗台、窗台栏杆和虹之龛在虹桥过来以前缩在墙里，看不见也上不去；虹快落到对岸时从墙里伸出来（月光大道那一版的做法）。
- 女神换了姿势：胸口左侧抱着一轮银盘似的月亮（离她 0.8 m 在前、0.35 m 在左，高约 3.8 m）。她的位置倒过来按镜子扫过的路线定：月亮正好在扫线上（H ≈ 160.6，135.7°）。月桥落地定在 H + 3，一层从落地处到水闸、瀑布后面时间都停在落地那一刻，所以在一层怎么走都照不到她，只能回月桥上。
- 瀑布不用关：镜子的月光和前后两层水帘的交点那一块水帘透开（中间几乎全透，边上一圈被月光照亮），光穿过去照到她。
- 影桥回来了。细桥的月影永远和细桥平行（东北—西南），只有子夜过后 H ≈ 194.2 那一刻才穿过水亭，影子从水亭伸向东北 47°、到离殿心 6.3 m。所以半桥只能从东北的池沿伸出来（和女神隔着水池斜对着），没法正对着她。要正对着她（西北），细桥的影子得指向西北，月亮要在东南约 79° 高，而这里的月亮最高只有 75°。
- 楼层叫法改成一层到四层（界面、说明、提示都改了）。

操作：WASD 移动，鼠标视角，Shift 快走，空格跳，E 互动，T 等时线，V 切换视角，H 说明，M 静音，R 回到上一个落脚点。

验证：通关机器人在无头 Chromium 里从小岛一路走到放下金苹果（白天、夜里各一段脚本），没有掉落重生：开场第一步前没有光、迈一步光到；夜里走月桥下来时女神不会亮，走回月桥 5.7 m 站住才亮，接着半桥、影桥、水亭。支线（机关 A → 暗的浮雕 → 旁边的 B、彩虹桥 → 窗台伸出 → 虹之龛 → 棱镜 → 塞勒涅、镜光 → 新的日之龛石台 → 两头走下去）单独跑通。

还没做：v0.5 以后的 UE 数据册；柱影钟的表盘；水面波光。

**彩虹链**：

1. L2 竖井朝中庭的一面有一块伊里斯浮雕，刻着一整圈虹，圈中间空着一个描金边的人形。
2. 转动虹台上的轮子，打开对面墙上的虹窗，阳光照进浮雕前的水帘。
3. 背对太阳，让自己影子的头落进那个人形。看到的彩虹和刻的虹重合，浮雕里的虹醒过来，变成一座虹桥。
4. 走过虹桥，到窗台上的虹之龛，拿到彩虹碎片。
5. 窗台随即伸出一块石板，上面立着一块水晶棱镜。转动棱镜，把七色光投到北墙另一块浮雕上。

### 实现要点

- **天象**：
  - 太阳沿一条固定的倾斜圆轨道运行，最高约 34°。
  - 满月在太阳的正对面，走同一种圆轨道（赤纬 +20°），子夜升到约 75°。
  - 日落后，星空绕北天极转动。
- **每层一段时间**：
  - 各层各有一条单调平滑的"方位角 → 时刻"曲线。每条曲线的接缝放在回廊断口、实体墙或竖井处。
  - 从一层踏上另一层的地方，两边的时间取相同的值。
  - 入夜后换成另一组曲线，时间随逆时针增加。两组曲线在接光台处相等。
- **水钟**：夜里竖井里的时间由水位决定，每放一层水，时间往前走一截。从 L3 放到 L2，月亮正好升过柱廊檐口，井里的月光才照得到水面。
- **顶层环道**：
  - 环道分成 32 级踏步，每级带一片光圈叶片。
  - 顺时针走时，前方 16 级按走过的角度逐渐升起，叶片外收。
  - 入夜后逆时针走，另外 16 级逐渐降下，最低一级落在 L3。
  - 每一级的高差不超过一步，站着的那一级会被慢慢托起。
- **光路**：
  - 在每扇窗的内侧取样，向太阳发射线。墙厚、窗框、柱子、滑板和岛影都会挡光，得到真实的受光截面。
  - 再沿光线方向求出四个角的落点，光束的下表面就是可以行走的面。
  - 铜镜按反射定律把光再射出去。
  - 站在光路上时，光路随时间摆动，会带着人一起走。
- **光路的宽容度**：
  - 判定宽度两边各多出 0.3 米。
  - 站在光上时，坡度上限放宽到 38°，雾浓度门槛也会降低。
  - 光路两侧有一道软护栏，只拦横向的滑出；下方 6.2 米内有地面时不拦，方便从光路走下来。
  - 离开光路后 0.14 秒内仍然可以起跳。
- **跳跃**：起跳速度 7.6 m/s，重力 22 m/s²，大约能跳 1.3 米高；走着跳约 2 米远，快走跳约 3.5 米远。回廊的栏杆跳起来也翻不过去。
- **三相像**：
  - 托镜石像有三个姿态：站在阳光里、面向太阳时举镜，这是唯一会反射的姿态；背对光时垂镜；面向月光时递镜。
  - 姿态随光线平滑过渡。
- **月光**：夜里，水面上只有亮着的东西才能踩。
  - **月光踏片**：水面分成约 1 米的踏片。一片踏片亮，要同时满足三条：水面平静；这片水被月光直接照到（用射线检测窗口，或按几何计算开口和楼板）；视线朝着月亮（相差不到 80°）。脚下那一片一直保留，直到离开它。
  - **月光大道**：起波纹的水面上，从脚下朝月亮方位每 0.3 米铺一步，只铺在有月光的水面上。站在上面时会一直保留。
  - **夜光石**：被金苹果照亮后可以踩，约 14 秒后慢慢暗下去。
  - **井中月**：井半径 0.9 米、深 2.4 米，月亮高过约 69° 才照得到井底。
- **彩虹与棱镜**：
  - 虹窗的位置和高度，是按浮雕那一刻的太阳方向和 42° 的虹角反推出来的。
  - 棱镜用斯涅尔定律逐色计算出射方向：顶角 45°，折射率从红 1.600 到紫 1.642。
  - 判定"落在眼睛上的是哪种颜色"，取离眼睛最近的那一道。
- **岛影**：
  - 西边海上有一座岩岛，朝塔的一段山脊是平直的。
  - 一块看不见的挡板放进阴影计算里，它的上沿和山脊在同一个阴影边界面上。所以塔上的影子、窗口的受光和岛的轮廓三者一致。
  - 顶层的时间曲线调成岛影一路追在人脚下。
- **体积光与彩虹**：
  - 场景先渲染到带深度的离屏目标，再在全屏合成里对光束做光线步进。
  - 散射用 Henyey–Greenstein 相位函数，并按光学厚度做饱和。
  - 彩虹按真实角度计算（主虹 40.6°–42.3°，副虹 50.3°–53.4°）。
- **接光台与虹门**：
  - 接光的时刻，正好是岛影漫过放在架上的苹果、还没漫到举起来的苹果的时刻。
  - 虹门跨在下一级踏步上，大小按"从接光台看去 42°"计算，日落时虹正好填满拱门。
- **性能**：
  - 大圆环切成 15° 一段，每扇窗只测附近的遮挡物。
  - 月光踏片只在月亮挪动、水位变化、而且人在附近时才重算。

### 验证

我用 Playwright 在无头 Chromium 里做了测试：

- **完整通关**：用脚本模拟按键，从出生点一路走到小亭，途中包括光阶的跳跃、借月、潮沟和夜光石。检查了每一次换层时时间是否接得上。
- **可选内容**：三个时辰龛和彩虹链（直到靛色照到塞勒涅的眼睛）各单独跑通。
- **反向检查**：
  - 进水口关着、背对月亮时，天池不亮。
  - 银月没被照亮时，铜链拉不动。
  - 水闸开着时，水庭不亮。
  - 月亮不够高时，放不下苹果，井底也不亮。
- **扫查捷径**：把各层各时刻的光路扫了一遍，没有发现能跳过谜题的捷径。
- **截图检查**：光圈天顶、日落虹门、浮雕和虹桥、棱镜色散、月光大道、夜光石、井中月等画面。

真机上的帧率、手感和声音还需要实际试玩。
