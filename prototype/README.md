# 原型

## 日月六关（`cloister/index.html`）

可以完整通关的灰盒原型，用浏览器里的 Three.js 做成：白天从正午的水庭走到日落的塔顶，入夜后再从塔顶走回水庭中心的小亭。整个原型是一个 HTML 文件，用较新的桌面版 Chrome、Edge 或 Safari 直接打开就能玩（需要联网加载 Three.js 和字体）。手机上也能打开，用触屏摇杆操作。

### 流程

| 关卡 | 楼层 | 要做的事 |
|---|---|---|
| 日1 · 正午·起雾 | L0 → L1 | 跟着水面上的光斑走到水闸旁，打开水闸，水雾让光显形；踩着光路登上 L1 的高窗 |
| 日2 · 午后·双窗 | L1 → L2 → L3 | 在 L1 顺时针走到北侧，下窗的光落在脚边，爬上 L2；拉杆让石板改挡下窗，打开狮首的水闸让雾升到塔顶；把石像转到正确的方向，镜子把光反射到 L3 |
| 日3 · 日落·最后一缕 | L3 → 顶层 | 从南侧高窗来的光桥跨过回廊的断口；穿过西边的甲门，沿绕塔坡道登上顶层。顺时针沿环道走，天花板像光圈一样收起，前方半圈升成阶梯；在最高一级举起金苹果，回头看虹填满虹门 |
| 日月回廊 · 日落之后 | 顶层 → L3 | 入夜后逆时针才是向前。顺着台阶往回走，阶梯落平；继续逆时针，另外半圈降成阶梯，通到 L3 |
| 月1 · 月升·天池 | L3 → L1 | 关掉墙上的进水口，面向刚出海的月亮，踩着水面上的月光走过天池；沿回廊走到东边的竖井，站上井里的月光，拉铜链降到 L1 |
| 月2 · 中夜·环渠 | L1 | 从竖井出来，沿 L1 逆时针绕一整圈；在石格窗投下的月光里走过环渠，打开闸轮，回到竖井再拉一次铜链 |
| 月3 · 子夜·归亭 | L0 | 关掉日1 打开的水闸，让水庭静下来；子夜前后走到东北，面向南方的月亮走过水面，把金苹果放进小亭的铜碗 |

### 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（Shift 快走） |
| 鼠标 | 转动视角（点击画面锁定鼠标，Esc 解锁） |
| E | 互动（水闸、拉杆、石像、金苹果、阀门、铜链、闸轮、铜碗） |
| T | 等时线视图：地上的铜线发光，天空画出太阳（入夜后是月亮）的轨道 |
| V | 第一 / 第三人称切换 |
| H | 规则和每关的提示 |
| M | 静音 |
| R | 从头再来 |

### 实现要点

- **天象**：太阳沿一条固定的倾斜圆轨道运行，最高约 34°；满月在太阳的正对面，走同一种圆轨道（赤纬 +20°），子夜升到约 75°。日落后星空绕北天极转动。
- **每层一段时间**：各层各有一条单调平滑的"方位角 → 时刻"曲线，每条曲线的接缝放在回廊断口、实体墙或竖井处。从一层踏上另一层的地方，两边的时间取相同的值。入夜后换成另一组曲线，时间随逆时针增加；两组曲线在接光台处相等。
- **顶层环道**：环道分成 32 级踏步，每级带一片光圈叶片。顺时针走时，前方 16 级按走过的角度逐渐升起，叶片外收；入夜后逆时针走，另外 16 级逐渐降下，最低一级落在 L3。每一级的高差不超过一步，站着的那一级会被慢慢托起。
- **光路**：
  - 在每扇窗的内侧取样，向太阳发射线。墙厚、窗框、柱子、滑板和岛影都会挡光，得到真实的受光截面。
  - 再沿光线方向求出四个角的落点，光束的下表面就是可以行走的面。
  - 铜镜按反射定律把上窗的光再射出去。
  - 站在光路上时，光路随时间摆动，会带着人一起走。
- **月光踏片**：水面分成约 1 米的踏片。一片踏片亮，要同时满足：水面平静；这片水被月光直接照到（天池、环渠、竖井用射线检测月窗、石格窗和竖缝；水庭按几何计算顶上的开口、各层楼板和小亭的穹顶）；玩家的视线朝着月亮（相差不到 80°）。脚下那一片一直保留，直到离开它。
- **岛影**：西边海上有一座岩岛，朝塔的一段山脊是平直的。一块看不见的挡板放在阴影相机的图层里，它的上沿和山脊在同一个阴影边界面上，所以塔上的影子、窗口的受光和岛的轮廓三者一致。顶层的时间曲线调成岛影一路追在人脚下。
- **体积光与彩虹**：
  - 场景先渲染到带深度的离屏目标，再在全屏合成里对光束做光线步进。
  - 散射用 Henyey–Greenstein 相位函数，并按光学厚度做饱和。
  - 彩虹按真实角度计算（主虹 40.6°–42.3°，副虹 50.3°–53.4°），出现在被光束照亮的瀑布水雾里，以及虹门处在岛影之上的喷泉水雾里。
- **接光台与虹门**：接光的时刻正好是岛影漫过放在架上的苹果、还没漫到举起来的苹果的时刻。虹门跨在下一级踏步上，大小按"从接光台看去 42°"计算，日落时虹正好填满拱门。
- **性能**：大圆环切成 15° 一段，每扇窗只测附近的遮挡物；月光踏片只在月亮挪动、水位变化、而且人在附近时才重算。

### 验证

我用 Playwright 在无头 Chromium 里做了测试：
- 用脚本模拟按键，从出生点一路走到小亭，完整通关一次，检查了每一次换层时时间是否接得上。
- 反向检查：进水口开着时天池不亮；背对月亮时踏片消失；闸没开时铜链拉不动；水闸开着时水庭不亮；月亮不够高时放不下苹果。
- 截图查看了光圈天顶、日落虹门和各个夜晚场景的画面。

真机上的帧率、手感和声音还需要实际试玩。

### 灰盒说明

尺寸、位置和时间曲线都是为了验证手感临时定的。三个时辰龛、水晶棱镜、月虹与黎明结局还没有做。
