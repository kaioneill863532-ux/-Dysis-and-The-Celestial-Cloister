# 原型

## 日1 灰盒原型（`day1/index.html`）

日1 开场的可玩灰盒，用浏览器里的 Three.js 做成。整个原型就是一个 HTML 文件，用较新的桌面版 Chrome、Edge 或 Safari 直接打开就能玩（需要联网加载 Three.js 和字体）。手机上也能打开，用触屏摇杆操作。

### 验证的三件事

1. **水雾让光束显形**：打开水闸后，瀑布脚下先起雾，细雾再向整座中庭扩散，光束从瀑布附近开始一点点显形。只有被雾照亮的光路才能踩。
2. **沿圆周走会改变时间**：太阳沿固定的倾斜圆轨道移动，光路随之转动；朝中心走，时间不动。开场一段的等时线很密，水面上的光斑会朝玩家滑过来，正好落到水闸旁的回廊上。
3. **踩着光路往上爬**：光路坡度约 32°，从回廊一直走到 L1 的高窗。窗台就是日1 与日2 的交界，走到这里原型结束。

### 实现要点

- **天象**：太阳沿一条固定的倾斜圆轨道运行（最高约 34°）。玩家所在的方位角经过一条单调平滑的曲线换算成时角，三个区段疏密不同：开场段密、光路段稀（太阳几乎不动，第一座光路很稳）、之后均匀推进。
- **光路**：在窗洞内侧取样，向太阳发射线，墙厚、窗框和外圈柱子都会挡光，得到真实的受光截面；再沿光线方向求出四个角的落点，光束的下表面就是可以行走的面。
- **体积光与彩虹**：场景先渲染到带深度的离屏目标，再在全屏合成里对光束做光线步进。散射用 Henyey–Greenstein 相位函数（朝着太阳看更亮）；彩虹按真实角度计算（主虹 40.6°–42.3°，副虹 50.3°–53.4°），只在被光束照亮的瀑布水雾里出现。
- **声音**：背景和声随时间连续变化，跨过时辰主线时滑向下一个和弦；朝中心走时音乐不变。

### 做原型时发现的几件事

- **光路常常贴着回廊内沿斜着穿过去**，回廊内沿离中庭太近时，光束的一侧会被栏杆切掉。现在 L1 回廊的内沿放在 12.2 米，窗台放在 10.8 米。
- **第一道彩虹的位置由物理决定**：彩虹只出现在背对太阳、视线与光线成 42° 的方向上。在这个布局里，站在南侧回廊朝瀑布看才能看见它，从水闸旁或光路上往下看都看不见。
- **室内的环境光不会被墙挡住**，必须把室内材质的环境光压得很低，只让窗里进来的直射光照亮空间，“最亮的地方就是目标”才成立。

### 灰盒说明

尺寸、位置和时间曲线都是为了验证手感临时定的。东北方向那块实体是水钟竖井，它截断了回廊，是本关时间的首尾接缝。因为日1 的光斑正好落在正东的回廊上，这一版把竖井移到了东北，而不是设计文档里的正东。
