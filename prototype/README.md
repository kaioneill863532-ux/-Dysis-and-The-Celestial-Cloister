# 原型

## 白天三关（`day/index.html`）

从正午的水庭走到日落的屋顶，可以完整通关的灰盒原型，用浏览器里的 Three.js 做成。整个原型是一个 HTML 文件，用较新的桌面版 Chrome、Edge 或 Safari 直接打开就能玩（需要联网加载 Three.js 和字体）。手机上也能打开，用触屏摇杆操作。

### 流程

| 关卡 | 楼层 | 要做的事 |
|---|---|---|
| 日1 · 正午·起雾 | L0 → L1 | 跟着水面上的光斑走到水闸旁，打开水闸，水雾让光显形；踩着光路登上 L1 的高窗 |
| 日2 · 午后·双窗 | L1 → L2 → L3 | 在 L1 顺时针走到北侧，下窗的光落在脚边，爬上 L2；拉杆让石板改挡下窗，打开狮首的水闸让雾升到塔顶；把石像转到正确的方向，镜子把光反射到 L3 |
| 日3 · 日落·最后一缕 | L3 → 屋顶 | 从南侧高窗来的光桥跨过回廊的断口；穿过西边的甲门，沿绕塔坡道登上屋顶；在接光台举起金苹果 |

### 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（Shift 快走） |
| 鼠标 | 转动视角（点击画面锁定鼠标，Esc 解锁） |
| E | 互动（水闸、拉杆、石像、金苹果） |
| T | 等时线视图：地上的铜线发光，天空画出太阳轨道 |
| V | 第一 / 第三人称切换 |
| H | 规则和每关的提示 |
| M | 静音 |
| R | 从头再来 |

### 实现要点

- **天象**：太阳沿一条固定的倾斜圆轨道运行，最高约 34°。
- **每层一段时间**：五个区域（L0、L1、L2、L3、屋顶）各有一条单调平滑的"方位角 → 时角"曲线，每条曲线的首尾接缝放在回廊断口或实体墙处。从一层踏上另一层的地方，两边的时间取相同的值。
- **光路**：
  - 在每扇窗的内侧取样，向太阳发射线。墙厚、窗框、柱子、滑板和岛影都会挡光，得到真实的受光截面。
  - 再沿光线方向求出四个角的落点，光束的下表面就是可以行走的面。
  - 铜镜按反射定律把上窗的光再射出去。
  - 站在光路上时，光路随时间摆动，会带着人一起走。
- **岛影**：西边海上有一座岩岛，朝塔的一段山脊是平直的。一块看不见的挡板放在阴影相机的图层里，它的上沿和山脊在同一个阴影边界面上，所以塔上的影子、窗口的受光和岛的轮廓三者一致。
- **体积光与彩虹**：
  - 场景先渲染到带深度的离屏目标，再在全屏合成里对光束做光线步进。
  - 散射用 Henyey–Greenstein 相位函数，并按光学厚度做饱和。
  - 彩虹按真实角度计算（主虹 40.6°–42.3°，副虹 50.3°–53.4°）。它出现在两个地方：被光束照亮的瀑布水雾里，以及屋顶虹门处在岛影之上的喷泉水雾里。
- **接光台与虹门**：接光台的时刻正好是岛影漫到 31.5 米的时刻。苹果放在架子上时在阴影里，举起来时在光里。虹门的半径按"从接光台看去 42°"计算，日落时虹正好填满拱门。
- **性能**：大圆环切成 15° 一段，每扇窗只测附近的遮挡物，射线检测的开销降了一个数量级。

### 验证

我用 Playwright 在无头 Chromium 里做了测试：用脚本模拟按键，从出生点一路走到接光台，完整通关一次。检查了每一次换层时时间是否接得上、每一段光路是否可走，并截图查看了各关的画面。真机上的帧率和手感还需要实际试玩。

### 灰盒说明

尺寸、位置和时间曲线都是为了验证手感临时定的。三个时辰龛、水晶棱镜和夜晚的三关还没有做。
