# 狄西斯的日落回廊 · 游戏设计文档

> 版本 0.3 ｜ 状态：日月十关已做成可完整通关的灰盒原型，三个时辰龛都能拿到

---

## 1. 概述

**类型**：以行走、观察和空间推理为核心的 3D 解谜游戏，写实美术风格。

**一句话**：移动的方式决定时间，光本身就是路。

**玩家需要掌握的基础行为**：移动、跳、观察、交互。

**故事**：玩家扮演日落女神狄西斯（Dysis），古希腊时序女神（Horae）中代表日落的一位。她借日光登上圆殿的最高处，用一枚金苹果接住最后一缕阳光；入夜后，再循着月光穿过水庭，把金苹果送到中心的小亭。子夜时，月光落在小亭上，金苹果被重新点亮。

月光本身就是被月亮反射的日光。所以这个故事其实是：狄西斯护送太阳的光，穿过它自己的回声。

**结构**：白天顺时针向上爬，夜里逆时针往下走。日月各五关，中间是日月回廊。

```
日1 L0→L1 → 日2 L1→L2 → 日3 L2 → 日4 L3 → 日5 L3→顶层（接光）
  → 日月回廊（环道降成阶梯）
  → 月1 L3 → 月2 L2 → 月3 L1 → 月4 L0 → 月5 L0（小亭）
```

- **关卡不按楼层分**。每一层的不同方位本来就是不同的时辰，所以同一层可以放好几关：L2 上有日2 的末段、日3 和月2；L3 上有日4、日5 的开头和月1；水庭里有日1、月4 和月5。
- 塔的高度不变：水庭 L0、三层回廊 L1–L3、顶层环道。
- 日1 和月4、月5 都在水庭：开场站着的那道干潮沟，子夜前会被海水灌满。
- 日3 和月2 都在托镜石像前：白天她把太阳递给你，夜里她把月亮递给你。
- 日4 和月1 都在 L3 南边的断口：白天从光里跳过去，夜里从水面上走过去。

## 2. 核心规则

### 2.1 移动与时间

- **沿圆周走**：时间流动，日月方位随之改变。
- **沿半径走**：时间不变，只有玩家相对日月的位置在变。
- **时间是空间坐标，不是倒计时**：往回走，时间就倒回。不存在"时间到了"的失败。
- **白天顺时针是向前，入夜后逆时针是向前**：金苹果接住最后一缕阳光的那一刻，天空交给月亮，向前的方向随之翻转。两种走法在接光台处时间相同，所以翻转时天不会跳。否则夜里往回走，太阳就会重新升起来。
- **每一层有自己的一段时间**：同一层的不同方位是不同的时辰。从一层踏上另一层的地方，两边的时间取相同的值。
- **时间接缝**：一圈首尾相接的地方时间会跳变。东侧的水钟竖井贯穿每一层，正好把每一圈截成"C"形，玩家不能在同一层绕过接缝。
- **竖井是一座水钟**：夜里站在井里的月光上拉铜链，水往下放一层，时间也往前走一截（从 L3 放到 L2 走 10，从 L2 放到 L1 走 4）。井里的时刻 = 进井时的时刻 + 这一趟水位下降走过的时间。
- **等时线**：地面嵌着青铜时刻线，每隔相同的时间画一根。线越密，走一步跨过的时间越多，日月走得越快；线越稀，日月几乎不动。
- **天象跟随狄西斯，其他一切按普通物理**：日、月、潮汐由她的位置决定；水流、水雾、机关按正常物理运行。玩家的操作不会因为时间倒回而被撤销。

### 2.2 日光：光路

一束日光同时满足以下条件时可以行走：

1. 是直射日光，从实墙上的窗进来（或经铜镜反射）；
2. 穿过的空气里有水雾，光束可见（丁达尔效应）；
3. 坡度不超过约 35°（楼梯的坡度）。

补充规则：

- **窗决定光路的截面**：窄缝是一根"光索"，宽窗是一条"光廊"。细格窗的光被窗棂切成一条条的，踩不上去。
- **光路以窗为铰链**：太阳高度变化让它升降、伸缩，方位变化让它左右旋转。
- **动桥 / 静桥**：光路的水平投影横跨等时线时，走在上面时间会流动，光路随之摆动，把人带到别处；大致沿径向时，时间几乎不变，光路稳定。
- **可以跳**：从一束光跳到另一束光。
- **站得住**（原型里定下的宽容度）：可踩的面比看得见的光两侧各宽 0.3 米；已经站上去时，雾稍淡一点、坡稍陡一点（到 38°）都不会让它消失；光路下面是深渊时，边上有一道看不见的护栏，往边上走会顺着光滑过去（护栏只拦和光垂直的那个方向）；刚踏空的 0.14 秒里还站得住，也还能起跳。

### 2.3 月光：夜里，水面上只有亮着的东西才能踩

- **月光踏片**：月光落在**平静**的水面上。玩家**面向月亮**时，被照着的水面是亮的，形成可行走的踏片；**背对**月亮时是暗的，踏片消失。
- **月光大道**：水面**起波纹**时，月亮的倒影被拉成一条从脚下伸向月亮的光带（真实现象）。站在水边面向月亮，它就铺出来；每一小段都朝着那一刻月亮所在的方位，沿着它走时间在变、月亮在挪，光带就跟着拐弯。
- **夜光石**：夜光石被强光照过就会发光，慢慢暗下去（磷光）。金苹果里存着最后一缕阳光，它靠近时，夜光石被照亮。
- **脚下那一片始终保留，直到离开它**，避免走着走着掉下去。
- 月光比日光暗得多，空气中的月光束不能行走。

白天"看得见的光才能走"，夜里"水面上只有亮着的东西才能踩"，这是同一条规则的两面。

### 2.4 水：水动成雾，水静成镜，水皱成道

同一套水钟系统，白天和夜晚反过来用：

- **白天**：让水从高处的狮首出水口泻下，砸碎成雾，雾让日光成路。
- **夜里**：让水静下来，水面成镜，月光成踏片；让水起波纹，倒影被拉长，月光成道。

### 2.5 三相像

时序女神的石像有三种形态，由照在她脸上的光决定：

- **日相**：脸上有阳光。她站直，举起手里的东西迎向太阳。
- **月相**：脸上有月光。她把手里的东西递向前方。
- **暗相**：脸上什么光都没有。她低下头，把手垂下来。

原型里的三相像就是托镜的那尊石像（见日3、月2）。形态完全由光自然决定，不需要玩家学额外的操作：转动底座让她面向光，她就醒过来。

### 2.6 失败与重试

没有死亡。从光路或踏片上掉下去，就落回下一层或上一个落脚点。

## 3. 天象模型

**原则：光学严格真实，天象由我们设计。**

反射、折射、色散、丁达尔效应、彩虹的 42° 都按真实物理；日月的轨道、高度和速度则按玩法需要设计。这在设定上站得住：这个世界里，天空本来就跟着时序女神的脚步转动。玩家对光学错误很敏感，却几乎不会察觉天体轨道和某个真实纬度对不上。

### 3.1 轨道

日月各沿一条**固定的倾斜圆形轨道**运行，全程不变。

| | 太阳 | 月亮 |
|---|---|---|
| 升起 | 东南偏东的海面 | 东北偏东，正对日落点 |
| 最高点 | 正南，高度约 35° | 正南，高度约 75°（子夜） |
| 落下 | 西南偏西的海面（甲门方向） | 西北偏西（游戏中不会看到） |

- 太阳最高只到约 35°，保证一整天的光路坡度都走得上去，也保证太阳永远照不进水庭里那口井。
- 月亮正对日落点升起，升起时天已经黑透。
- 这组参数和真实世界中纬度地区冬季的满月夜很接近：冬天太阳走得低，满月走得高。

### 3.2 光路的变化从哪里来

1. **每关用轨道的哪一段**：倾斜圆轨道的顶部几乎是水平移动，两侧主要是上升或下沉。
2. **沿轨道的速度**：由等时线的疏密决定。
3. **装置**：大幅度的方向变化交给铜镜，分色交给棱镜，开合交给窗、百叶、柱影和水雾。

### 3.3 各关的天象

| 关卡 | 轨道区段 | 光怎么变 |
|---|---|---|
| 日1 | 太阳在最高点附近，几乎水平移动 | 光路像钟表指针一样水平旋转 |
| 日2 | 太阳沿轨道下降 | 以升降、伸缩为主，兼有旋转 |
| 日3 | 太阳降到十一二度 | 高窗的光斜着横穿中庭，落在托镜石像上 |
| 日4 | 太阳贴近海面，十度左右 | 三束平行的光从错落的高窗里射进来 |
| 日5 | 太阳沉到岩岛后面 | 岛影从塔底往上爬，光路放平 |
| 日月回廊 | 日落 → 月出 | 往回走下阶梯时天黑透，满月从日落点的正对面升起 |
| 月1 | 月亮刚出海，十一二度 | 贴地的月窗在天池上铺出长长的月光大道 |
| 月2 | 竖井里水放一层，月亮升到三十多度 | 东北墙上的月窗把月光送到托镜石像脸上 |
| 月3 | 月亮爬升到四五十度 | 石格窗把月光切成一排踏片 |
| 月4 | 月亮升到五六十度 | 顶上的开口开始照进水庭，潮水涨起来 |
| 月5 | 月亮到正南，约 75° | 穿过小亭的圆眼落进铜碗；只有这时候照得到井底 |

**贯穿全局的规律：光源越低，只有高处能照到；光源越高，光才能照进深处。**太阳最高时，狄西斯在最底层；太阳落到海面时，她在塔顶。月亮刚升起时，她在塔顶；月亮到天顶时，她回到最底层，一直照到井底。

### 3.4 天象的三条规矩

1. **连续顺滑**，不跳变。
2. **一关之内单调**：天体沿轨道只朝一个方向走，不来回。
3. **大轮廓可信**：白天太阳整体下降、变红，最终落进海里；月亮从日落的对面升起，最终到达天顶。

### 3.5 让玩家看得懂轨道

- **浑天仪**：接光台是一架青铜浑天仪。金环是太阳的轨道，银环是月亮的轨道，倾角和游戏里的天空完全一致。水庭入口处还有一架小的同款浑天仪。
- **等时线视图**：打开时，除了地面的等时线，还会在天空画出本关太阳（或月亮）的轨道弧线。

## 4. 建筑

### 4.1 总体意象

一座建在世界西缘海崖上的圆塔，面朝海上的日落。**白天它是一座日晷，夜晚它是一座水钟。**古希腊人白天用日晷、夜里用水钟计时，雅典的风之塔就是一座同时带有日晷和水钟的真实建筑。

- **形制**：多层希腊圆殿叠成的塔，中间是上下贯通的中庭，顶上是光圈天顶。
- **墙体**：里面一圈实心石墙，外面一圈柱廊。光只能从实墙上的窗进来。
- **十二时柱**：外圈十二根柱子对应十二位时序女神，两柱之间就是一个时辰。
- **水系统**：引山泉入屋顶天池，经狮首出水口、环渠和竖井逐层下泄，最后注入水庭。水庭经海门里侧的潮沟与海相通，所以有潮汐。

### 4.2 剖面

```
          ◯  光圈天顶：天花板由一圈叶片组成，它的边就是顶层环道
 顶层 ──  环道（一级级踏步，能升成阶梯或降成阶梯）· 接光台（浑天仪 + 金苹果）· 虹门 · 坡道口的两道铜栅
 L3 ───  上环廊 · 南边断口里的天池 · 月窗（贴地宽窗）· 光阶的三扇高窗（176° 铜栅、194°、208.5° 窗里是日之龛）· 甲门
 L2 ───  双窗滑板（249°）· 狮首出水口 · 托镜石像（38°）· 东北月窗（43°）· 竖井门框上的银色弯月
         虹台（贴着竖井朝中庭的一面）与伊里斯浮雕 · 西南的虹窗（214°，细格窗）与窗台、虹之龛、棱镜 · 北墙的塞勒涅浮雕
 L1 ───  下环廊 · 东南断口里的环渠 · 石格窗 · 闸轮
 L0 ───  黑石镜池（有潮汐）· 海门里侧的潮沟与夜光石 · 井台（井底是月之龛）· 水闸 · 中心小亭（穹顶开圆眼）· 小浑天仪
      东侧贴着外墙有一口水钟竖井，朝东开一道通高的竖缝，在 L3、L2、L1、水庭各停一站
```

### 4.3 材质与色彩

- 西半边用暖色大理石，会被夕阳染成金粉色；东半边用青白石材。
- 水庭池底用黑色玄武岩，深色池底的倒影最清晰。
- 时刻线、镜面、浑天仪用抛光青铜；接光台和金苹果用金；月锁用银；塞勒涅的眼睛是青金石。

### 4.4 物理校核

- **窗开在高处（高侧窗）**：光要先越过本层回廊的地板，才能投进中庭。
- **厚墙窗洞像一段短管**：只有太阳大致对准时才透光，所以每扇窗都有自己的"开放时段"。
- **回廊内沿要离中庭够远**：光路常常贴着回廊内沿斜着穿过去（原型中回廊内沿在 12.2 米）。
- **天顶开口正下方的中庭必须完全畅通**：子夜的月光要从顶上落到小亭和井台上。
- **低月的光几乎贴着塔身走**：塔外柱廊的檐口在 16–17.2 米高，会挡住它。所以夜里给低处水面照明的窗要开得低、开得宽；竖井停在 L2 时，要等月亮升过三十度才照得到井水（见 2.1 的水钟）。
- **室内做不出完整的虹拱**：室内的光是窗口进来的一束，普通的窗只有两米多宽，被照亮的水雾装不下一道 42° 的虹。所以虹台的做法是：开一扇高窗（虹窗高 2.8 米），人站得离水帘只有一米多，虹也就只有一米来宽，整圈落在光里（见 9.2）。
- **东北的窗白天永远是暗的**：太阳一整天都在南边和西边，所以东北墙上的月窗、东南的石格窗白天不会在中庭里投下多余的光斑。

## 6. 关卡

### 日1「正午·起雾」L0 → L1（教学关）

- **天象**：太阳在轨道最高点附近，几乎水平移动。光路像钟表指针一样旋转，坡度不变。
- **教的内容**：光要有雾才能走；沿圆周走，时间流动；朝中心走，时间不变。
- **流程**：低潮时从海门走进来，脚下是一道干潮沟；跟着地上的光斑走；打开水闸，水雾升起，光束显形，出现第一道彩虹；调整站位，让光路落到脚边；逆着光往上走，进入 L1。完整分镜见第 10.2 节。

### 日2「午后·双窗」L1 → L2

- **动桥**：在 L1 上顺时针走到北边，从一条来自 L2 低窗的光路爬上去。它横跨等时线，往上走时会摆动。
- **双窗滑板**：拉杆让石板换一扇窗挡。通关时滑板必须停在高窗，日3 才有光。
- **狮首水闸**：打开后，水雾升到塔顶，L2 以上的光才能走。

### 日3「申时·三相」L2

- **托镜石像**：底座有五个卡槽。她背对阳光时是暗相，垂着镜子；转到面向高窗的格子，阳光照到她脸上，她变成日相，举起镜子，把光反射出去。第五格把光送到 L3 东南，这就是去 L3 的路。
- 设计要点：形态完全由光决定，底座随时能转，不设额外的锁。玩家只需要注意到"她在光里才会举起镜子"。
- **伊里斯浮雕（可选，虹之龛）**：见第 9 节。

### 日4「酉时·光阶」L3 东南 → L3 西

- **光阶**：南墙上三扇错落的高窗，傍晚的光从里面射进来，是三束平行的光，一束比一束高 0.5–0.7 米，中间隔着约一米的空。
  - 第一束的脚落在 L3 东南的回廊上，可以直接走上去，但它的窗口装着铜栅，进不去。
  - 第二束的脚落在够不着的地方，只能从第一束上横着跳过去。它的窗台通往 L3 西段，这是主线。
  - 第三束再高一些，要从第二束上跳过去。它的窗里是日之龛（可选）。
- 走在光上时方位在变，时间在变，三束光一起微微摆动；因为是平行的，它们之间的距离不变。

### 日5「日落·最后一缕」L3 西 → 顶层

- **影线**：落日沉到西边海上一座岩岛的山脊后面时，岛影从塔底往上爬，低处先暗下去。**这就是狄西斯必须登顶的原因。**
- 穿过甲门，沿绕塔坡道走上顶层。
- **高潮：光圈天顶**：顺时针沿环道走，叶片像相机光圈一样往外收，前方半圈一级级升成阶梯，另外半圈保持水平。最高一级在入口正对面，上面是接光台。岛影一路追着人往上爬，直到最后一级：岛影刚好漫过放在架上的苹果，举起来的苹果还在光里。接住最后一缕阳光。
- 回头看，虹门跨在下一级踏步上，一道红色的半圆彩虹正好填满它。

### 日月回廊「日落之后」顶层 → L3

- 接光以后，入夜后逆时针才是向前（见 2.1）。
- 顺着台阶往回走，升起的半圈一级级落平；走过入口继续逆时针，另外半圈一级级降下去，成为通往 L3 的阶梯。两半加起来是一条完整的螺旋。
- 往下走的时候天慢慢黑透，星星出来，满月从日落点的正对面升起。

### 月1「月升·天池」L3（夜间教学关）

- **天象**：月亮刚出海，十一二度高，在正东偏北。
- **天池**：阶梯的最后一级落在 L3 南边断口的天池旁。墙上的进水口开着，水面起着波纹。
- **月光大道**：站在水边面向月亮，一条闪烁的光带从脚下一直铺到天池东头的回廊。踩上去，沿着它走过去。背对月亮，它就暗了。
- **另一种走法**：关掉进水口，水面静下来，贴地的月窗在水面上照出一片片月光踏片，面向月亮踩过去。两种都能通关，第一次见到的是月光大道。
- **竖井**：沿东南回廊走到东边的水钟竖井，站在井里的月光上拉铜链。

### 月2「初夜·借月」L2

- **水钟**：水从 L3 放到 L2，时间也往前走了一截，月亮升到三十多度，高过了塔外柱廊的檐口，井里的月光才照得到水面。
- **刹杆**：想继续往下放，铜链却拉不动：闸上有一根刹杆卡着，刹杆穿过井壁，外头嵌着一弯银月。
- **借月**：出竖井往西走几步，就是白天那尊托镜石像。她还面朝西南，是暗相。转动底座，让她面向东边：东北墙上的月窗正好把月光照到她脸上，她变成月相，把镜子递出去。再转一格，反射的月光落在竖井门框的银月上，刹杆松开。回到竖井，拉铜链，降到 L1。
- 这一关要做的事都在眼前：刹杆、银月、托镜石像、月窗，不需要回头去找以前的东西。

### 月3「中夜·环渠」L1

- **天象**：月亮爬升到四五十度。
- 从竖井出来，沿 L1 逆时针绕一整圈，月亮一路爬高。
- **环渠**：L1 东南的断口里是一段环渠，外墙上是石格窗。月光从窗棂之间投下来，在水面上铺出一排踏片。
- 过了环渠，墙上的闸轮打开竖井通往水庭的闸。从这一侧回到竖井，再拉一次铜链，降到水庭上方。

### 月4「夜半·潮」L0

- **水闸**：日1 打开的第一个水闸还开着，瀑布让水庭起波纹。出竖井就能听到，也看得到闸轮在旁边。关掉它。
- **潮沟**：往东北走，海门里侧那道开场时干着的潮沟，现在被涨起来的海水灌满了。海水从海门涌进来，水面一直在动，没有踏片，也没有月光大道。
- **夜光石**：沟里有几块矮石墩，没在水下几厘米。捧着金苹果走近，它们被照亮，发出青白的光，亮着的时候踩得住，过一会儿慢慢暗下去。一块一块踩过去。
- 设计要点：金苹果从接光起就一直捧在手里，这是第一次它自己的光派上用场。

### 月5「子夜·归亭」L0（终章）

- **天象**：月亮到了正南，约 75°。
- **归亭**：水庭已经静下来，月光从顶上的开口照进来。面向南方的月亮，从东北踏着月光走过水面，登上中心小岛。小亭的穹顶开着圆眼，月亮升到最高时，月光穿过圆眼落进铜碗。放下金苹果，它在月光里重新亮起来。
- **井中月（可选，月之龛）**：去小岛的路边有一座井台。井深而窄，只有月亮高过 69° 时才照得到井底，也就是子夜前后；太阳最高只有 35°，永远照不进去。井口刻着一只伸手捞月的猴子。子夜时井底的水面上浮着一轮月亮，那就是一片月光：跳下去，落在月亮上。井底的井壁上是月之龛，拿到月亮碎片后，潮水涌进井里，把你托上来。
- **露水**：子夜前后，露天的石面上闪着细碎的光。
- **黎明结局**（集齐三个时辰龛后解锁，未做）：天亮时，发光的金苹果把光交给清晨的时序女神。

## 8. 时辰龛（成就：日、虹、月）

每个龛用一种不同的光来发现。都在主线旁边，一眼能看到，但要真正理解对应的光才进得去；都不挡主线，也不需要回头去做什么。集齐三个解锁黎明结局。

| 龛 | 位置 | 发现方式 |
|---|---|---|
| 日之龛 | 日4，光阶第三束光的窗里 | 从第二束光上再跳一次 |
| 虹之龛 | 日3，虹窗下的窗台 | 让伊里斯浮雕里的虹醒过来，踩着虹桥过去 |
| 月之龛 | 月5，井台的井底 | 子夜时井底浮着一轮月亮，跳进去 |

## 9. 彩虹与色散

### 9.1 真实物理

- 彩虹是以"太阳正对面那一点"为圆心、半径约 42° 的圆，**只有太阳在身后时才看得见**。
- 这个圆心就是观察者**自己影子头部**所在的位置。
- 虹只出现在被阳光照着的水滴里。站在很近的水雾前，能看到一整圈虹围着自己影子的头。
- 棱镜的色散：顶角 45° 的铅水晶，红光偏得最少，紫光最多，相差约 2°。离棱镜近时颜色叠在一起；**大约 30 米外，七色才铺开一米多**。前面加一道铜缝，颜色才分得清。
- 越接近日落，阳光里的蓝紫光越少。

### 9.2 在游戏里的用法

**第一道虹（日1）**：打开第一个水闸后，光束穿过瀑布的水雾，被照亮的水雾里出现一道小彩虹。它不动声色地告诉玩家：看到彩虹时，太阳在你身后。

**伊里斯浮雕与虹桥（日3，虹之龛）**：

1. **虹台**：L2 东北，竖井朝中庭的那一面刻着彩虹女神伊里斯的浮雕，前面挑出一个比回廊低半米的虹台。浮雕上刻着一整圈虹，虹的中间空着一个人形，描着金边。竖井满水时，溢水从浮雕上沿洒下一道细水帘。
2. **虹窗**：对面西南墙上有一扇高而窄的细格窗，外面关着铜百叶。虹台上的闸轮拉开它，傍晚的光穿过中庭，正好罩住浮雕和水帘。窗的位置按"傍晚站在虹台上的那一刻，光正好罩住浮雕"反推出来。
3. **对齐**：背对太阳，站在离水帘一米多的地方，一整圈虹就围着自己影子的头出现在水帘里。让影子的头住进那个空着的人形，看见的虹就和刻着的虹重合。
4. **虹桥**：浮雕里的虹醒过来，从虹台沿着虹窗的来光拱过中庭，落在虹窗下的窗台上。
5. **虹之龛**：窗台右手的墙里是虹之龛，里面是彩虹碎片。打开后，窗台边伸出一块石板，上面立着棱镜，正好接住虹窗射进来的光。
6. **棱镜与塞勒涅**：棱镜把光分成七色，投过中庭，落在 L2 北墙的月神塞勒涅浮雕上。转台有八个卡槽，每转一格，就有一种颜色落到她的眼睛上，从红到紫。她的眼睛是青金石镶的：第六格，靛色落进去，她醒过来，接着是一段众神借伊里斯传话的对话。

提示：没开启时，和两块浮雕互动都有一句提示。伊里斯："背对太阳的人，才看得见她。让你影子的头，住进那个空着的人形里。"塞勒涅："她的眼睛是青金石镶的，七色之中，她只认第六色。"

这一整条都是可选的，主线（托镜石像把光送上 L3）完全不经过它。虹窗是细格窗，它的光踩不上去，所以窗台只能从虹桥过去，不会被当成捷径。

**虹门（日5）**：日落时，虹门跨在接光台前一级踏步上，一道红色的半圆彩虹正好填满它。人是穿过它走上最后一级的，回头才看见虹。

### 9.3 众神的对话

- 伊里斯：日和月从来不同时在天上，所以你们的话，一直是我替你们传。
- 赫利俄斯：告诉塞勒涅：今天最后一缕光，我交给那个在塔上奔跑的时辰了。
- 塞勒涅：狄西斯？她总是来得太晚，又走得太早。
- 伊里斯：所以她才需要这座塔。她沿着回廊每走一步，你们就在天上挪一寸。
- 塞勒涅：那就让她把光带下来吧。我在水里等她。
- 赫利俄斯：等她集齐了日、虹、月，黎明会来接她。

伊里斯（Iris）这个名字在希腊文里是虹，在今天还指眼睛的虹膜和相机的光圈：浮雕上的虹、塞勒涅的眼睛、塔顶的光圈天顶，落在同一个名字上。

## 10. 引导与反馈

### 10.1 引导原则

这个游戏的主角就是光，而光本来就是最好的指路牌。

- **最亮的地方永远是下一个目标。**用光照引导视线，不用文字。
- **终点始终看得见。**白天中庭越往上越亮；夜里每一层都能透过中庭看到中心小亭。
- **一次只教一件事，先让玩家看见，再让玩家使用。**
- **一关要做的事都在眼前**：解开一处以后往前走，不应该发现还要回到前面，用已经解过的东西去做一件不那么必要的事。夜里用到白天的装置（托镜石像），是因为主线正好又经过它，而且它就在眼前。
- **随意试错**：时间可以倒回，也没有死亡。

### 10.2 开场分镜（前五分钟，没有文字教程）

1. **远景**：海崖上的圆塔沐浴在正午的阳光里，塔顶的浑天仪一闪。
2. **入场**：狄西斯从海门走进来。正值低潮，脚下是一道干潮沟，沟里几块矮石墩。门口的小浑天仪上，金环画出太阳今天的路。
3. **看见光**：水庭里唯一亮的地方是地上一块光斑。空气干净，看不到光束，玩家会自然走向它。
4. **学会第一条规则**：通往光斑的是一条弧形石道，玩家必然是沿圆周在走。光斑随着脚步连续滑动，停下它就停下。
5. **第一个惊喜**：光斑停在一个水闸旁。打开后高处水帘落下，水雾升起，光束从瀑布附近开始一点点显形。
6. **第一次登高**：光路落点差一点够不着。往回走两步，光路落到脚边，踩上去，逆着光往上走。
7. **第一道彩虹**：光束穿过瀑布的水雾，被照亮的那团水雾里有一道小彩虹，要走到南侧回廊回头看瀑布才看得见。

### 10.3 反馈：连续而安静

- 光斑、光路和影子随步伐连续滑动。停下它们就停；朝中心走，它们不变。
- 背景是一段持续的和声，随时间连续变化。往前走，和声慢慢推进；往回走，它倒回去；停下，它停在当前的和弦上。只有跨过十二根时辰主柱时，和声才轻轻换到下一个和弦。**玩家是在用脚步演奏这一段时间。**
- 真正的事件音只留给少数时刻，比如光路成形、踏片出现，而且音量很轻。

## 12. 设计原则

1. **永远不会卡死**：夜里依赖的状态，要么由白天主线必然留下（比如高窗、托镜石像），要么夜里还能去修改。
2. **隐藏区域不挡主线**，也不会被当成捷径。
3. **先看见，再使用**：每个新机制都先让玩家安全地看到一次。
4. **流畅，不折返**：解开一处以后，不应该还要回头去做一件不那么必要的事（见 10.1）。
5. **难度随物理自然递进**：低处的月亮光带长而连贯，高处的月亮踏片短而零碎。
6. **一物多用**：同一个地点、光线或装置，在不同时间要有不同的用途。

## 13. 风险与原型

### 13.1 需要验证的风险

- **动桥的反馈循环**：走在动桥上时，位置改变时间，时间改变光路，光路又带动位置。手感是否舒服、会不会发散。
- **关卡交界的时间衔接**：交界门槛两侧的时间映射要对齐，而且过渡要让玩家察觉不到。
- **判定的宽容度**："面向月亮"要给多大的角度范围；光路要宽多少、护栏要多软，才能既符合直觉又不会太宽松。
- **跳跃的手感**：光阶的缝隙和高差对键鼠、触屏是否都合适。

### 13.2 原型

日月十关已经做成可以完整通关的灰盒，见 `prototype/cloister/index.html` 和 `prototype/README.md`。原型用浏览器里的 Three.js 做成，打开网页就能玩。正式开发用什么引擎另行决定。

### 13.3 原型里定下来的做法

- **每一层一段时间**：L0、L1、L2、L3、屋顶各有自己的时间曲线和接缝。从一层踏上另一层的地方，两层的时间取相同的值。
- **光路会带着人走**：站在光路上时，记下人在光路上的位置；时间一变、光路一摆，人跟着光路移动。
- **跨中庭的光路，时间要放缓**：经过铜镜的光路要求入射光一直照在镜子上，所以这一段的时间几乎不动。
- **掉下去**：落差不超过 6.5 米就正常落地；更高就回到上一个落脚点。回廊栏杆跳起来也翻不过去。
- **位置由光反推**：虹窗、棱镜的高度、塞勒涅的眼睛、月锁的位置、东北月窗，都是程序按"那一刻的日月方向 + 光线怎么走"算出来的，所以谜题在物理上一定成立。
- **白天的实际布局**：双窗在 249°；托镜石像在 L2 38°，第五格把光反射到 L3 东南；光阶的三扇窗在 176°（铜栅）、194°、208.5°；甲门在 264°，门外有阳台和绕塔坡道；接光台在屋顶东北。
- **虹台**：浮雕在竖井朝中庭的一面（80°），空着的人形头部离地 1.4 米，对的站位离浮雕 1.1 米；虹窗在 214°、高 19.1–21.9 米。虹桥长 22.5 米，从虹台（79°）拱到窗台（219°）。
- **棱镜**：顶角 45°，折射率从红 1.600 到紫 1.642（铅水晶）；立在窗台伸出的石板上，高 20.9 米；七色落在 L2 北墙 14.5° 附近，相邻两色在眼睛处相隔约 13 厘米。判定"落在眼睛上的是哪种颜色"取离眼睛最近的那一道，所以站在窗台不同的地方（时刻差一点）也不会误判。
- **顶层**：环道从入口 334° 顺时针分成 16 级踏步，每级升 0.45 米，最高一级在入口正对面，高出屋面 7.2 米；逆时针同样 16 级，降到 L3。
- **月光踏片**：水面分成约 1 米的踏片。一片踏片亮，需要：水面平静；被月光直接照到；视线方位与月亮相差不到 80°。脚下那一片一直保留。
- **月光大道**：以 0.3 米为一步，从水边朝那一刻的月亮方位一步步铺过去，直到水面没有月光或到了池边；宽 1.3 米。
- **月2 的物理限制**：竖井停在 L2 时水面正好和柱廊檐口一样高，月亮低于约 30° 时照不到井水，所以从 L3 放到 L2 让水钟走 10。
- **月锁**：托镜石像递镜时，第二格反射的月光第一次碰到的东西是竖井 L2 那扇门外侧的门框（73°，离地 1.1 米），银月就嵌在那里。
- **潮沟**：38°–52°，比回廊低 35 厘米。约 136 以后潮水漫进来；夜光石被金苹果照亮后约 14 秒慢慢暗下去。
- **井台**：镜池 28°、离塔心 6.2 米；井半径 0.9 米、深 2.4 米，所以月亮要高过约 69°。
- **没有做**：黎明结局；日月以外的时辰龛铭文和短诗；夜里用双窗滑板让子夜的高月从高窗照进来这一处联动。
