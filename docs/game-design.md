# 狄西斯的日月回廊 · 游戏设计文档

> 版本 0.1 ｜ 状态：概念设计已定，待原型验证

---

## 1. 概述

**类型**：以行走、观察和空间推理为核心的 3D 解谜游戏，写实美术风格。

**一句话**：移动的方式决定时间，光本身就是路。

**玩家需要掌握的基础行为**：移动、观察、交互。

**故事**：玩家扮演日落女神狄西斯（Dysis），古希腊时序女神（Horae）中代表日落的一位。她借日光登上圆殿的最高处，用一枚金苹果接住最后一缕阳光；入夜后，再循着月光穿过水庭，把金苹果送到中心的小亭。子夜时，月光落在小亭上，金苹果被重新点亮。

月光本身就是被月亮反射的日光。所以这个故事其实是：狄西斯护送太阳的光，穿过它自己的回声。

**结构**：白天向上爬，夜里往下走，每一层都会在不同的光线下经过两次。

```
日1(L0→L1) → 日2(L1→L3) → 日3(L3→屋顶，接光) → 日月回廊 → 月1(屋顶) → 月2(L2) → 月3(L0，小亭)
```

- 日1 和 月3 都在水庭
- 日2 和 月2 都在 L2
- 日3 和 月1 都在顶部

## 2. 核心规则

### 2.1 移动与时间

- **沿圆周走**：时间流动，日月方位随之改变。
- **沿半径走**：时间不变，只有玩家相对日月的位置在变。
- **时间是空间坐标，不是倒计时**：往回走，时间就倒回。不存在"时间到了"的失败。
- **每一关对应一段时间**，一关可以跨好几层。关与关的交界设在明确的门槛（窗台、平台）上，两边的时间在那里对齐。一关之内仍然严格遵守"只有沿圆周走才改变时间"。
- **时间接缝**：一圈首尾相接的地方时间会跳变。东侧的水钟竖井贯穿每一层，正好把每一圈截成"C"形，玩家不能在同一层绕过接缝。
- **等时线**：地面嵌着青铜时刻线，每隔相同的时间画一根。线越密，走一步跨过的时间越多，日月走得越快；线越稀，日月几乎不动。需要精细调整的谜题区用稀疏的线，需要明显变化的地方用密的线。
- **天象跟随狄西斯，其他一切按普通物理**：日、月、潮汐由她的位置决定；水流、水雾、机关按正常物理运行。玩家的操作不会因为时间倒回而被撤销。

### 2.2 日光：光路

一束日光同时满足以下条件时可以行走：

1. 是直射日光，从实墙上的窗进来；
2. 穿过的空气里有水雾，光束可见（丁达尔效应）；
3. 坡度不超过约 35°（楼梯的坡度）。

补充规则：

- **窗决定光路的截面**：窄缝是一根"光索"，宽窗是一条"光廊"，石格窗是几条平行的光路。可走的光路建议宽 1–1.5 米。
- **光路以窗为铰链**：太阳高度变化让它升降、伸缩，方位变化让它左右旋转。
- **动桥**：光路的水平投影横跨等时线。走在上面时间会流动，光路随之摆动，把人带到别处。
- **静桥**：光路大致沿径向，与等时线平行。走在上面时间几乎不变，光路稳定。
- 玩家自身不遮光。

### 2.3 月光：踏片

- 月光落在**平静**的水面上。玩家**面向月亮**、处在反射光的方向上时，这片水面是亮的，形成可行走的踏片；**背对**月亮时是暗的，踏片消失。原理和现实中水面上的"月光大道"一致。
- **玩家脚下那一片踏片始终保留，直到玩家离开它**，避免走着走着掉下去；其他踏片仍按朝向显示或消失。
- 水面有波纹时倒影破碎，不能行走。
- 石格窗会在水面投出一排踏片。
- 月光是斜着照下来的，所以水位一变，踏片会沿光的方向水平滑动。
- 月光比日光暗得多，空气中的月光束不能行走。它在夜雾中隐约可见，只作为提示。

### 2.4 水：水动成雾，水静成镜

同一套水钟系统，白天和夜晚反过来用：

- **白天**：让水从高处的狮首出水口泻下，砸碎成雾，雾让日光成路。离落水越近雾越浓，所以哪里有落水，哪里的光才能走。开关一个水闸，就是在决定哪片区域能走。
- **夜里**：让水静下来，水面成镜，月光成踏片。

### 2.5 失败与重试

没有死亡。从光路或踏片上掉下去，就落回下一层或上一个落脚点。

## 3. 天象模型

**原则：光学严格真实，天象由我们设计。**

反射、折射、色散、丁达尔效应、彩虹的 42° 都按真实物理；日月的轨道、高度和速度则按玩法需要设计。这在设定上站得住：这个世界里，天空本来就跟着时序女神的脚步转动。玩家对光学错误很敏感，却几乎不会察觉天体轨道和某个真实纬度对不上。

### 3.1 轨道

日月各沿一条**固定的倾斜圆形轨道**运行，全程不变。

| | 太阳 | 月亮 |
|---|---|---|
| 升起 | 东南偏东的海面 | 东北偏东，正对日落点 |
| 最高点 | 正南，高度约 35° | 天顶（子夜） |
| 落下 | 西南偏西的海面（甲门方向） | 西北偏西（游戏中不会看到） |

- 太阳最高只到约 35°，保证一整天的光路坡度都走得上去。
- 月亮正对日落点升起（虹门需要这一点），升起时天已经黑透。
- 这组参数和真实世界中纬度地区冬季的满月夜很接近：冬天太阳走得低，满月走得高。所以它看起来是自然的。

### 3.2 光路的变化从哪里来

轨道固定不变，光路的多样性来自以下三处，都不会让日月看起来在乱跑：

1. **每关用轨道的哪一段**：倾斜圆轨道的顶部几乎是水平移动，两侧主要是上升或下沉。只要选对区段，同一条轨道就能自然产生"旋转"和"升降"两种光路运动。
2. **沿轨道的速度**：天体始终在同一条轨道上，只是时快时慢，就像椭圆轨道上的行星近日点快、远日点慢。速度由等时线的疏密决定。
3. **装置**：大幅度的方向变化交给石雕托镜，分色交给棱镜，开合交给窗、柱影和水雾。

### 3.3 各关的天象

| 关卡 | 轨道区段 | 光路怎么变 |
|---|---|---|
| 日1 | 太阳在最高点附近，几乎水平移动 | 像钟表指针一样水平旋转，坡度几乎不变 |
| 日2 | 太阳沿轨道下降 | 以升降、伸缩为主，兼有旋转 |
| 日3 | 太阳贴近海面，越来越慢 | 渐渐放平成水平光路；影线从塔底上升 |
| 日月回廊 | 日落 → 月出 | 虹门处时间变化最快 |
| 月1 | 月亮刚出海，斜着上升 | 月光大道长而连贯，边旋转边缩短 |
| 月2 | 月亮爬升 | 圆眼投下的光斑在中庭里移动，踏片变短 |
| 月3 | 月亮缓缓收向天顶 | 光斑向中心收拢，最后落在小亭上 |

**贯穿全局的规律：光源越低，只有高处能照到；光源越高，光才能照进深处。**

所以太阳最高时，狄西斯在最底层；太阳落到海面时，她在塔顶。月亮刚升起时，她在塔顶；月亮到天顶时，她回到最底层。光源的高度和她的高度此消彼长，整个关卡结构就由这条规律推出。

### 3.4 天象的三条规矩

1. **连续顺滑**，不跳变。
2. **一关之内单调**：天体沿轨道只朝一个方向走，不来回。
3. **大轮廓可信**：白天太阳整体下降、变红，最终落进海里；月亮从日落的对面升起，最终到达天顶。

### 3.5 让玩家看得懂轨道

- **浑天仪**：接光台是一架青铜浑天仪，古希腊真实存在的天文仪器。金环是太阳的轨道，银环是月亮的轨道，倾角和游戏里的天空完全一致，金苹果放在它的中心。水庭入口处还有一架小的同款浑天仪，让玩家一进门就能看到"太阳会怎么走"。
- **等时线视图**：打开时，除了地面的等时线，还会在天空画出本关太阳（或月亮）的轨道弧线和刻度，玩家能预判天体接下来往哪走。

## 4. 建筑

### 4.1 总体意象

一座建在世界西缘海崖上的圆塔，面朝海上的日落。**白天它是一座日晷，夜晚它是一座水钟。**古希腊人白天用日晷、夜里用水钟计时，雅典的风之塔就是一座同时带有日晷和水钟的真实建筑。

- **形制**：多层希腊圆殿叠成的塔，中间是上下贯通的中庭，顶上是万神殿式的天顶圆眼。
- **墙体**：里面一圈实心石墙，外面一圈柱廊，也就是希腊圆殿本来的形制。光只能从实墙上的窗进来。
- **十二时柱**：外圈十二根柱子对应十二位时序女神，两柱之间就是一个时辰。
- **等时线**：地面嵌青铜时刻线，做法类似欧洲大教堂地面上的子午线。
- **水系统**：引山泉入屋顶天池，经狮首出水口、环渠和竖井逐层下泄，最后注入水庭。水庭经地下水道与海相通，所以有潮汐。

### 4.2 剖面

```
          ◯  天顶圆眼（白天关着：留住水雾；日落后打开：雾散，月光进来）
 屋顶 ──  日月回廊（露天柱廊）· 接光台（浑天仪 + 金苹果）· 虹门 · 天池 · 甲门(西) / 乙门(东) · 月之龛
 L3 ───  上环廊 · 水晶棱镜窗 · 虹之龛
 L2 ───  双窗滑板（南偏西墙）· 石雕托镜 · 环形水渠 + 水闸 · 狮首出水口
 L1 ───  下环廊 · 日之龛
 L0 ───  黑石镜池（通海，有潮汐）· 石台 · 水闸 · 中心小亭 · 小浑天仪
      中间是贯通上下的中庭；东侧外墙贴着一口水钟竖井，朝东开一道通高的窄缝
```

### 4.3 材质与色彩

- 西半边用暖色大理石，会被夕阳染成金粉色；东半边用青白石材。
- 水庭池底用黑色玄武岩，深色池底的倒影最清晰。
- 时刻线、镜面、浑天仪用抛光青铜；接光台和金苹果用金；另有石格窗和雪花石膏。

### 4.4 物理校核

建筑必须满足以下条件，光路和踏片才能按设计成立：

- **窗开在高处（高侧窗）**：光要先越过本层回廊的地板，才能投进中庭。
- **厚墙窗洞像一段短管**：只有太阳大致对准时才透光，所以每扇窗都有自己的"开放时段"。
- **外圈柱廊的柱影**随时间扫过窗口，某些时刻会把窗遮住，形成天然的时间开关。
- **光路尺度**：太阳不是点光源，光路边缘会随距离略微模糊，但 20–30 米内仍然清楚。中庭直径按这个尺度设计。
- **回廊内沿要离中庭够远**：光路常常贴着回廊内沿斜着穿过去，内沿太靠近中庭时，光束的一侧会被栏杆切掉（原型中 L1 回廊内沿放在 12.2 米）。
- **双窗滑板下方的回廊地面要开采光井**：子夜的月亮很高，从高窗射下的月光很陡，要穿过 L2、L1 回廊地面的格栅采光井，才能落到水庭的水面上（月3 依赖这一点）。
- **L0 的水面延伸到回廊下方**，回廊的柱子立在水里，这样陡的月光才有水面可落。
- **天顶圆眼正下方的中庭必须完全畅通**：子夜的月光要从圆眼笔直落到小亭上，中间不能有任何桥或平台。

## 5. 装置

| 装置 | 位置 | 白天 | 夜晚 |
|---|---|---|---|
| 水闸与狮首出水口 | 各层 | 放水成雾，决定哪片区域能走 | 关水，让水面静下来成镜 |
| 环渠水闸 | L2 | 关闭：环渠放干成路；水改道从狮首泻进竖井，溅起水雾；竖井蓄水 | 打开：竖井与环渠连通，随水面降到 L2；环渠重新注满 |
| 双窗滑板 | L2 南偏西墙 | 一块雪花石膏板在上下两扇窗之间滑动，开一扇就关一扇。被盖住的窗仍透出柔光，但不成路 | 开着的高窗放进子夜的高月 |
| 石雕托镜 | L2 | 一尊时序女神石像托着抛光铜镜，转动底座改变朝向，把日光反射上去 | 把圆眼投下的月光打到需要的地方 |
| 水晶棱镜窗 | L3 | 把光路分成彩色光带 | 无 |
| 天顶圆眼 | 屋顶中心 | 关着，留住水雾 | 日落后打开，放进月光 |
| 虹门 | 屋顶回廊正南 | 日落时红虹填满拱门 | 月虹填满拱门 |
| 水钟竖井 | 东侧，贯穿各层 | 蓄水；同时是各层回环的时间接缝 | 随水面下降的"电梯" |

石雕托镜的形制参考古希腊真实的"女像柱镜"：一尊小小的女性立像托着一面圆镜。石头本身做不了镜子，镜面必须是抛光的青铜或银。叙事上：**白天她把太阳递给你，夜里她把月亮递给你。**

## 6. 关卡

### 日1「正午·起雾」L0 → L1（教学关）

- **天象**：太阳在轨道最高点附近，几乎水平移动。光路像钟表指针一样旋转，坡度不变。
- **教的内容**：光要有雾才能走；沿圆周走，时间流动；朝中心走，时间不变。
- **流程**：
  1. 低潮时从海门走进水庭。
  2. 沿弧形石道跟着地上的光斑走。
  3. 打开水闸：水帘落下，水雾升起，光束显形，出现第一道彩虹。
  4. 调整站位，让光路落到脚边。
  5. 逆着光往上走，进入 L1 的高窗。

  完整分镜见第 10.2 节。
- **伏笔**：石台的布局、岛上的小亭、竖井的入水口。

### 日2「午后·双窗」L1 → L3（核心机制关）

- **天象**：太阳沿轨道下降。光路以升降、伸缩为主，兼有旋转。
- **动桥**：从 L1 爬上一条来自 L2 低窗的光路。它横跨等时线，往上走时会摆动，下端扫过 L1 的日之龛，一闪而过。
- **双窗滑板**：换到高窗后，光路更长，能横跨整个中庭。
  - 从高窗沿光路往下走，它边走边摆，接近径向时稳定下来。
  - 从哪端上、往哪走，决定它停在石雕托镜上（主线），还是指向日之龛（隐藏）。
- **石雕托镜**：把高窗的光反射向上，通往 L3。这一步必须开着高窗，所以**通关时滑板一定停在高窗**。
- **环渠水闸**：一个动作，三个后果。
  - 渠底放干，成为通往托镜背后的路；
  - 水改从狮首泻进竖井，溅起的雾让 L2–L3 之间的光路显形；
  - 竖井开始蓄水。
- **水晶棱镜窗**：通往虹之龛，见第 9 节。

### 日3「日落·最后一缕」L3 → 屋顶

- **天象**：太阳贴近海面，越来越慢，光路渐渐放平。
- **影线**：太阳沉向海平线时，海平线的影子从塔底往上爬，低处的窗先暗下去。**这就是狄西斯必须登顶的原因。**
- **玩法**：时间越往后影线越高，所以可走的区域是一条螺旋。玩家要找出一条始终在影线之上的螺旋上升路线。走错了就退回去，时间随之倒回。
- **水雾**：天池溢出的水帘让顶层中庭的雾最浓，几乎水平的落日光路在这里最清楚。
- **高潮**：
  - 穿过甲门走上屋顶，沿回廊走向虹门，落日就在身后。
  - 只有一个位置是对的，也就是日落的那一刻。站到那里，最后一缕阳光穿过柱隙，落在浑天仪中心的金苹果上。
  - 与此同时，喷泉水雾里一道红色的半圆彩虹正好填满虹门，狄西斯的影子站在彩虹正中。
- **收尾**：打开天顶圆眼。热空气从圆眼升出去（烟囱效应），中庭的雾很快散尽，白天的光路全部消失。白天由玩家亲手结束。

### 日月回廊「日月交替」虹门 → 乙门

- 甲门到虹门是日3 的高潮；虹门到乙门是日夜交替。
- 虹门处的等时线最密：穿门而过，暮色就转成了夜色。满月从日落点的正对面升起。
- 从柱间往下看：潮水涨进水庭、淹没石台，水面起了薄雾，白天开过的窗在月光里显出轮廓。
- 这一段没有谜题，是观景，也是夜晚的地图预览。

### 月1「月升·天池」屋顶（夜间教学关）

- **天象**：月亮刚出海，斜着上升。低处的月亮在水面上拉出一条长长的月光大道。
- **场景**：屋顶北半圈是天池，四周的柱子把月光大道切成一段段。**柱隙就是"孔洞"。**
- **教的内容**：
  - 面向月亮才有踏片；
  - 沿圆周走，月亮移动，光带换到另一道柱隙；
  - 进水口让一片水面波动、倒影破碎，关掉它，水面平静下来才能走。
- **一个选择**：进水口同时供给虹门的喷泉。可以先留着它看月虹、找到月之龛，再关掉它让天池平静下来。
- **出口**：东北角的水钟竖井。
  - 白天它已经被灌满，东侧通高的窄缝让月光始终照在井中水面上。
  - 站上踏片，拉动铜链打开 L2 的环渠水闸。竖井与环渠连通，两边水位趋平（连通器原理），狄西斯站在踏片上随水面降到 L2。
  - 白天放干的环渠同时被重新注满。

### 月2「中夜·水钟」L2

- **天象**：月亮爬升到半空。月光从天顶圆眼斜射进中庭，投下一个圆斑，就像万神殿里那个随时间移动的光斑。它是这座建筑夜里的"时针"。
- **环渠**：注满且平静，是一整圈环形水面。沿环渠走会推进时间，圆斑也跟着移动。要让它落在前方的渠面上，同时面向月亮，才能一段段往前走。
- **石雕托镜**：圆斑扫到镜面时，转动它，把月光打到被柱子挡住的那段渠上。同一面镜子，换了一个光源。
- **途经双窗滑板**：高窗开着，但月亮还没转到这扇窗前，窗外一片漆黑。玩家多半不会在意，这是为月3 埋的伏笔。
- **出口**：沿环渠的溢水石阶下到 L1 和水庭。如果白天进过日之龛，龛里的暗梯是直通水庭的捷径。

### 月3「子夜·归亭」L0（终章）

- **天象**：月亮缓缓收向天顶，越来越慢。
- **大潮**：白天踩过的石台大多沉入水下，只剩几块高的露出水面。水面薄雾里月光束隐约可见，只作为提示。
- **我帮了我**：
  - 月亮转到南方高空，光从白天打开的高窗射下，穿过回廊地面的采光井，石格窗在水面投出一排踏片，指向小亭。
  - 如果当时开的是低窗，光只会落在 L1 的地板上，到不了水面。
- **潮位**：潮水随时间上涨，踏片随之向墙根方向滑动。沿圆周走会同时改变月亮位置和潮位，两者要一起考虑。
- **高石台（进阶规则）**：站得越高，视线角度越不同，原本暗的水面可能变亮。
- **结局**：子夜，月亮到达天顶，圆眼的月光笔直落在中心小亭上。狄西斯放下金苹果，金苹果被月光点亮。
- **黎明结局**（集齐三个时辰龛后解锁）：天亮时，发光的金苹果把光交给清晨的时序女神。日落、黑夜、黎明，完成一个循环。

## 7. 日月联动

| 日时的操作 | 当时的目的 | 到了月时 |
|---|---|---|
| 关闭环渠水闸 | 放干渠水走渠底；造雾；竖井蓄水 | 开闸后随水面降到 L2，环渠被注满 |
| 滑板停在高窗 | 用长光路，配合石雕托镜 | 子夜的高月从这扇窗照进来，在水面铺出通往小亭的路 |
| 转动石雕托镜 | 把阳光反射上 L3 | 夜里重新转它，把圆眼进来的月光打到环渠上 |
| 打开天顶圆眼 | 让雾散去，结束白天 | 月光从圆眼落下，成为夜里的时针和终章的光 |
| 低潮时走过的石台 | 白天的落脚点 | 涨潮后只剩高石台，你已经知道它们在哪 |
| 进入日之龛 | 可选探索 | 夜里是下到水庭的捷径 |
| 日落红虹填满虹门 | 日3 高潮的"对的时刻" | 让玩家记住虹门，夜里用月虹找到月之龛 |

## 8. 时辰龛（成就：日、虹、月）

每个龛用一种不同的光来发现。每个都能从主线上瞥见一眼，但要真正掌握对应的机制才进得去。龛里是一幅时序女神浮雕和一句铭文，三句合起来是一首短诗。集齐三个解锁成就和黎明结局。

| 龛 | 位置 | 发现方式 |
|---|---|---|
| 日之龛 | L1 | 日2 爬动桥时，桥的下端扫过它；之后要找出让光路稳定指向它的上桥方式 |
| 虹之龛 | L3 | 棱镜把光路分成彩色光带，只有紫色那一侧能通到龛里，而且有时限 |
| 月之龛 | 屋顶，甲门塔楼的墙上 | 月虹填满虹门时，狄西斯的月影正好落在门后墙上的浮雕上，那里就是入口 |

## 9. 彩虹与色散

### 9.1 真实物理

- 彩虹是以"太阳正对面那一点"为圆心、半径约 42° 的圆，**只有太阳在身后时才看得见**。
- 这个圆心就是观察者**自己影子头部**所在的位置。
- 太阳越低，彩虹越完整。日落时是一个完整的半圆，而且偏红。
- 月亮够亮时，水雾里也会出现**月虹**，人眼看上去是银白色的。
- 越接近日落，阳光里的蓝紫光越少（晚霞发红也是这个原因）。

### 9.2 在游戏里的用法

**第一道虹（日1）**：打开第一个水闸后，光束穿过瀑布的水雾，被照亮的水雾里出现一道小彩虹。这是整个游戏的第一个惊喜，也不动声色地告诉玩家：看到彩虹时，太阳在你身后。原型验证了它的位置：只有站在南侧回廊背对太阳看瀑布时才看得见。

**棱镜彩虹桥（日2，虹之龛）**：

- L3 的一扇高窗里嵌着一块水晶棱镜，光路穿过它会散成一条彩色光带。
- 真实的色散角很小，约 2°。所以靠近棱镜时颜色叠在一起，还是白光；**大约 30 米外，颜色才分开约 1 米**。
- 设计上让光带末端跨过一道边缘：红色那半落在平台上（主线），紫色那半越过边缘继续延伸，通到龛里。
- 太阳越低，紫色那一侧越暗。所以**通往龛的那半条路有时限**，必须在太阳落得太低之前走过去。

**虹门，一门两虹（日3 / 月1，月之龛）**：

- 日月回廊正南立着一道拱门，旁边有喷泉水雾。拱门的大小，刚好能框住站在门前适当位置的人所看到的彩虹。
- **日落时站在门的西侧**：落日在身后，一道红色半圆彩虹正好填满拱门，狄西斯的影子站在彩虹正中。这一刻同时也是最后一缕阳光落在金苹果上的时刻。
- **入夜后站在门的东侧**：刚升起的月亮在身后，一道银白月虹同样填满拱门，月影正好落在门后墙上的浮雕里，指出月之龛的入口。
- 物理上成立的原因：月亮从日落点的正对面升起，所以落日的虹和月出的虹朝向正好相反。同一道门，一面框住日虹，一面框住月虹。

## 10. 引导与反馈

### 10.1 引导原则

这个游戏的主角就是光，而光本来就是最好的指路牌。

- **最亮的地方永远是下一个目标。**用光照引导视线，不用文字。
- **终点始终看得见。**
  - 白天：越高的窗晒到太阳的时间越长（这是真实的），中庭越往上越亮，视线自然往上走。
  - 夜里：每一层都能透过中庭看到中心小亭。
- **一次只教一件事，先让玩家看见，再让玩家使用。**比如日之龛，先在动桥上瞥见，之后才想办法进去。
- **随意试错**：时间可以倒回，也没有死亡。
- **卡住时给温柔的提示**：狄西斯会转头看向相关的光；夜里的薄雾会显出月光的走向。

### 10.2 开场分镜（前五分钟，没有文字教程）

1. **远景**：海崖上的圆塔沐浴在正午的阳光里，塔顶的浑天仪一闪。一个镜头交代清楚目标在哪。
2. **入场**：狄西斯从海门走进来。正值低潮，露出水面的石台是唯一的路，没有岔路。门口的小浑天仪上，金环画出太阳今天的路。
3. **看见光**：水庭里唯一亮的地方是地上一块光斑。空气干净，看不到光束，玩家会自然走向它。
4. **学会第一条规则**：通往光斑的是一条弧形石道，玩家必然是沿圆周在走。光斑随着脚步连续滑动，停下它就停下，玩家在不知不觉中学会第一条规则。这一段的等时线较密，保证变化足够明显，但运动始终是连续的。
5. **第一个惊喜**：光斑停在一个水闸旁，这是视野里唯一能互动的东西。打开后高处水帘落下，水雾从瀑布脚下升起、向中庭扩散，光束从瀑布附近开始一点点显形。
6. **第一次登高**：光路落点差一点够不着。玩家刚学过"走动会让光移动"，往回走两步，光路落到脚边，踩上去，逆着光往上走。
7. **第一道彩虹**：光束穿过瀑布的水雾，被照亮的那团水雾里有一道小彩虹。彩虹只出现在背对太阳的方向，所以要走到南侧回廊回头看瀑布才看得见，它是留给愿意多看一眼的玩家的。

### 10.3 反馈：连续而安静

**视觉为主**：

- 光斑、光路和影子随步伐连续滑动。停下它们就停；朝中心走，它们不变。玩家靠这种"我动，它才动"的对应关系学会规则。
- 铜线本身不发声，只在低角度的阳光下泛起一点金属反光。

**声音做成音乐，而不是提示音**：

- 背景是一段持续的和声，随时间连续变化。往前走，和声慢慢推进；往回走，它倒回去；停下，它停在当前的和弦上。
- 朝中心走时音乐不变，玩家能"听出"时间没有在动。
- 只有跨过十二根时辰主柱时，和声才轻轻换到下一个和弦。它是音乐的一部分，不是"叮"的一声。
- 效果上，**玩家是在用脚步演奏这一段时间**。
- 真正的事件音只留给少数时刻，比如光路成形、踏片出现，而且音量很轻。

## 12. 设计原则

1. **永远不会卡死**：夜里依赖的状态，要么由白天主线必然留下（比如高窗），要么夜里还能去修改。
2. **隐藏区域不挡主线。**
3. **先看见，再使用**：每个新机制都先让玩家安全地看到一次。
4. **难度随物理自然递进**：低处的月亮光带长而连贯，高处的月亮踏片短而零碎，所以夜晚越往后越难。
5. **一物多用**：同一个地点、光线或装置，在不同时间要有不同的用途。

## 13. 风险与原型计划

### 13.1 需要验证的风险

- **动桥的反馈循环**：走在动桥上时，位置改变时间，时间改变光路，光路又带动位置。这个循环的手感是否舒服、会不会发散，需要尽早用原型测试。
- **关卡交界的时间衔接**：交界门槛两侧的时间映射要对齐，而且过渡要让玩家察觉不到。
- **月光踏片的判定宽容度**："面向月亮"要给多大的角度范围，才能既符合直觉又不会太宽松。

### 13.2 原型第一步

先做日1 开场这一段的灰盒原型，只验证三件事：

1. 水雾让光束显形，有雾的光才能走；
2. 沿圆周走时，太阳沿轨道顶部水平移动，光路随之连续旋转；
3. 踩着光路往上爬的手感。

已完成，见 `prototype/day1/index.html` 和 `prototype/README.md`。原型用浏览器里的 Three.js 做成，打开网页就能玩。正式开发用什么引擎另行决定。
