换到软件里

太阳与月亮

UE 里的轨道

太阳、月亮各走一条固定的倾斜圆轨道（纬度 35°；太阳赤纬 −21°，正午最高 34°；月亮赤纬 +20°，最高 75°）。整个游戏只用一个量来推它们：时角 H（度）。游戏里显示的钟点 = 12:00 + H/15 小时。H 由人站的位置决定（见下面“时间怎么走”）。

输入：H（度）。太阳用 h = H、δ = −21°；月亮用 h = H − 180、δ = +20°；φ = 35°

东 E = −cosδ · sin h

北 N = sinδ · cosφ − cosδ · cos h · sinφ

上 U = sinδ · sinφ + cosδ · cos h · cosφ

方位 az = atan2(E, N)（0° 北，顺时针）　高度 alt = asin(U)

UE 平行光（+X 朝北、+Y 朝东）：Pitch = −alt，Yaw = az + 180，Roll = 0

平行光的朝向是“光照过去的方向”，所以 Yaw 要从太阳所在的方位转 180°，Pitch 取负数（往下照）。白天用太阳那盏，夜里换成月亮那盏；远处岩岛（240°，463 m 外，山脊高 56.9 m）的剪影负责日落时把光挡住。
