日落回廊重构方案

这一版把谜题交还给建筑和光。开关、拉杆、滑板、阀门和铜链都去掉了；玩家能改变的只有两样：自己站在哪里（这决定日月在哪），和几尊可以转动的雕像。白天，阳光从南和西南照进来，落在北面和东面；夜里，月亮从东边升起，光穿过打开的光圈，顺着西墙一层层往下沉，玩家跟着它下到水亭。

改了什么

保留

  • 时间由位置决定：白天顺时针向前，夜里逆时针向前
  • 看得见的光能踩
  • 托镜像（日、月、暗三相）
  • 伊莉丝浮雕、虹桥、棱镜、塞勒涅浮雕
  • 光圈天顶的环道、虹门、岛影
  • 两架浑天仪、三个神龛

改动

  • 开场：从海上的石柱走进神殿
  • 雾：来自东侧终年不停的瀑布
  • 登顶：从穹顶中央的圆眼进去
  • 夜里的规则：月石
  • 每一层的等时线均匀
  • 窗和柱子各有分工；建筑用一套比例

去掉

  • 水闸、拉杆和双窗滑板、狮首水闸
  • 天池进水口、竖井铜链、闸轮、百叶
  • 月光踏片、月光大道、夜光石、井中月
  • 甲门、阳台和殿外坡道

规则

时间

沿弧走，时间流动，日月跟着动；沿半径走，时间不变。每一层的等时线疏密均匀，层与层之间可以不同。

楼层之间的光路都是偏在一侧的弦，不穿过中庭中心：穿过中心时，几步之内方位角变很多，时间会跳一大截。唯一穿过中心的是圆眼那一束，它沿半径，走上去时间不动。

白天

看得见的光能踩。雾来自东侧的瀑布：中庭里终年有雾，回廊里雾很淡，所以只有穿过中庭的光能走。

能踩的光有连续的体积、清楚的边界和水雾托着；纹样窗的碎光、棱镜的细色散光和月光束换一种画法，一眼看得出不能踩。

夜里：月石

月石是一种半透明的白色石头（透石膏，selenite，名字就来自塞勒涅）。月光直射或经铜镜反射照到它时，它显出另一种形态：墙里的通路、雕像的另一种姿态、收拢的半桥。普通的柱、梁、楼板和台阶始终是实体。月光束本身不能踩。

一段通路要在同一时刻整段都在月光里（中间没有被柱影截断），才算读完；读完以后一直保留，玩家绕去入口时不会因为月亮挪走又关上。

月光往下沉

月亮从东边升起，光穿过打开的光圈落在西墙上。月亮越高，光落得越低：约 10° 时照到 L3，19° 到 L2，31° 到 L1，48° 到水庭（见图 1）。玩家一层层往下走，就是追着月光往下。

操作

雕像转过以后保持朝向。解谜靠两个动作交替：转一格，再沿回廊走，看光和影怎么变。

窗

  • 主光窗：拱下全开，只放在光路需要的开间。窗洞斜切，所以只在它服务的时段透光。立面按南北轴对称：西半边的主光窗为太阳服务，东半边的为月亮服务。
  • 日常采光窗：窗台高、窗窄、窗洞深。光只落在本层的地面或墙上，不进中庭，所以不会成路；它们提供气氛和方向，也是柱影钟的表盘。
  • 纹样窗：每个拱头的半月形石格。投下的是碎光，不能踩，可以在墙上投出图案线索。
  • 盲拱壁龛：外面是浅浮雕的盲拱，里面是雕像龛。托镜像、天鹅、双子都住在这里。这是万神庙、佛罗伦萨洗礼堂都用过的做法，外观的节奏不变，里面也不会多出一束误导的光。

柱子

  • 外圈 24 根柱子在墙外。它们的影子只落在日常采光窗的光斑里（柱影钟），或者是玩家要读懂的遮挡。
  • 内圈柱廊的每根柱子，要么在光扫过的范围之外，要么就是谜题里的遮挡物。主光轴上的帕拉第奥母题，让光在它服务的时段里只从中间的宽拱穿过。
  • 每根柱、每道栏杆、每个拱肩，都要检查它在整段关卡时间里怎样影响光。原型会自动扫一遍各层各时刻的光路来做这项检查。

瀑布

  • 从屋顶的天池经东侧的水阶落到水庭，终年不停。它是雾的来源，也把每一层截成一个 C 形，就是时间接缝。
  • 傍晚的阳光照在它的水沫上，背对太阳能看到虹（伊莉丝浮雕就在旁边）。
  • 夜里月亮从它后面升起，月光穿过水帘，在西墙上投下流动的水纹。白天水庭的水面把波光映在拱顶上。

路线

白天

序 · 海上石柱神殿南边的海上 → 南门太阳 34°，正南
  • 玩家站在海上一根石柱的顶上，柱顶立着一道天然石拱。太阳在身后。
  • 光穿过石拱，落进石柱自己的影子里，斜着铺过海峡，落到神殿的南门，海浪的水沫让它显形。沿着它走下去，从南门进入神殿。
  • 第一课：绕着柱顶走，时间在变，光一会儿穿过石拱、一会儿被挡；朝神殿走（沿半径），时间不动。
  • 背对太阳，水沫里有一道虹，正好框住神殿。
日1 · 正午·水庭水庭：南 → 西 → 西北太阳 34° → 32°
  • 子午线：南墙高处一个小孔，太阳的圆斑落在西侧地面一条嵌铜的时辰线上（ΣΤ Ζ Η Θ），随脚步滑动，把人领到西北。
  • 第一束光：从 L1 西南的主光窗斜穿中庭，落到水庭西北。它是一条偏在一侧的弦，走在上面光会跟着时间摆动。
  • 水面的波光映在拱顶上。
日2 · 午后·柱廊L1：西南 → 西 → 北太阳 32° → 29°
  • L1 北侧回廊内沿是爱奥尼柱廊，通往 L2 的主光轴上是帕拉第奥母题：中间一个宽拱，两边各一个窄开间。
  • 走动时太阳在动，光束在柱廊上横着滑。大多数时候它被柱子切成两半，每一半都太窄、踩不上；只有穿过中间宽拱的那一段时间，落到回廊上的是完整的一束。
  • 柱影钟：日常采光窗在墙上投下光斑，外圈时辰柱的影子从光斑里扫过。
日3 · 申时·三相L2：西南 → 西太阳 29° → 25°
  • 托镜像站在西侧的壁龛里。转动底座时，日常采光窗把她的影子投在龛壁的壁画上；转到对的格子，影子补上壁画里的缺口，说明这个朝向有意义。
  • 在这个朝向上，太阳照到她脸上，她举起铜镜，把上窗的光反射上 L3。这是主线。
日4 · 酉时·光阶L3：南 → 西 → 北 → 东北太阳 25° → 17°
  • 光阶：西侧三扇相邻、同高的主光窗。太阳斜着照进来，三束平行的光在中庭里一束比一束高，从一束跳到下一束。立面上三扇窗一样高，高差来自光的斜度。
  • 延迟反射（日之龛）：走在光阶上时间在走，另一扇窗的光扫到楼下那尊托镜像上，还是日3 转好的朝向。反射光从侧下方升起，贴到光阶旁边的石台；跳过去，就是日之龛。
  • 路过西侧时，会看到一尊女神像，身后的浮雕上几只天鹅中间空着一块（月2 用）。
日5 · 日落·最后一缕L3 东北 → 圆眼 → 屋顶太阳 17° → 落山
  • 圆眼光柱：太阳降到约 17° 时，光从穹顶正中的圆眼射下来，脚正好落在 L3 东北的回廊上。它沿半径，走上去时间不动，是白天唯一静止的光。
  • 伊莉丝浮雕（虹之龛，可选）：在光脚旁边、瀑布的水沫前。站进光里，自己影子的头落进浮雕上空着的人形，一圈虹出现在水沫里；虹桥伸到对面，那里是虹之龛，棱镜把光分成七色投到北墙的塞勒涅。
  • 穿过圆眼上到屋顶，朝太阳走到环道边（西南），顺时针往上。岛影一路追上来。
  • 最高一级在西北偏北：走到这里时人正好背对夕阳，看到虹填满拱门；穿过拱门，浑天仪里的太阳就是金苹果。台阶全部升起时它亮起来；取下它，天黑了。

夜里

月1 · 月升·读墙屋顶 → L3 东北月亮 0° → 5°，东北偏东
  • 逆时针往回走，升起的台阶一级级落平；过了西南继续逆时针，另外半圈降成阶梯，经过南面和瀑布的源头，下到 L3。
  • 最后一段楼梯藏在月石墙里。月亮刚出海，从东北的窗照进来，窗间墙墩的影子把楼梯截成几段。往前走一步，月亮挪一点，影子跟着滑。找到整段楼梯同时被照亮的那一刻，它就读完了，留下来。
  • 这是第一次教月石的规则。
月2 · 初夜·天鹅L3：东北 → 北 → 西月亮 7° → 13°
  • 白天见过的女神像。月光从打开的光圈照过来，她变成一只白天鹅，墙上的影子是一只黑天鹅。
  • 转动底座，让黑天鹅的朝向和浮雕上的天鹅一致；再沿回廊走，让月亮把影子挪进空白处。雕像离浮雕约 2.5 米时，影子随脚步上下移动约 0.3 米。
  • 吻合时，浮雕旁边的墙显出下行的楼梯。
  • 铭文（建议）："湖上七只天鹅，第七只只在月光里回来。"
  • 和芭蕾正好反过来：芭蕾里奥杰塔白天是天鹅、夜里变回人；这里月光照出的真形是天鹅，影子是黑天鹅奥吉莉亚。
  • 制作时倒着来：先定白天鹅的形体和正确的月角，实际投出影子，再按影子画浮雕的空白。
月3 · 中夜·双子L2 西月亮 13° → 27°
  • 一尊固定的像站在西侧，光圈照下来的月光在这一段时间里一直照着她，显出半边拱。另一尊藏在厚墙后的侧龛里，直射月光照不到。
  • 托镜像还在这里。转动她，把月光反射进侧龛，沿一条径向轨道照过去。另一尊显形后，沿轨道把她推向固定的那尊：沿半径走，月亮不动，光一直在；推的人在雕像后面，挡不住光；光没了，雕像停在原地。
  • 两尊合拢，拱背补成一座桥，跨过地面的断口，通往下 L1 的楼梯。合拢的拱卡住托镜像的底座，她的朝向从此固定。
  • 建议用狄俄斯库里双子（卡斯托耳与波吕丢刻斯）：一个凡人、一个永生，宙斯让他们轮流在天上和冥府，正好是日夜交替。
月4 · 夜半·镜下L1：西南 → 南 → 东南月亮 27° → 40°
  • 楼梯的下一段藏在南侧、L2 楼板下的夹层里。月亮已经很高，直射太陡，只能擦过楼板边。
  • 沿 L1 逆时针走，月亮升高，楼上托镜像的反射光慢慢扫进楼板下面，照出夹层里的通道。观察点能同时看到铜镜、反射光和目标。
  • 夹层里有一扇小窗，往外看是白天走过的平台底部。
  • 月之龛（支路）：继续往前走，反射光扫到另一处，照出一个小龛。
  • 上一关把托镜像卡在唯一的朝向，所以这一关一定可解。
月5 · 子夜·水亭水庭：东北 → 北 → 西北 → 水亭月亮 40° → 75°，转到正南
  • 下行的楼梯穿过瀑布后面的墙，出到水庭东北，沿岸逆时针走。
  • 池里有两段收拢的月石半桥。A 在西北岸边，光圈照下来的月光照得到它，但亭柱和上层楼板边的影子会挡住一部分；B 在亭子檐下，永远在亭顶的影子里，只能靠岸边托镜像反射。
  • 沿岸走选月角，转铜镜选反射方向。要同时满足三件事：A 被照亮；镜子被照亮；反射光越过展开的 A 照进檐下的 B。两段同时展开、接合，才是一座稳定的石桥。
  • 桥沿半径通向亭子，走过去时间不动。浑天仪的月亮位置是一个空托，放上金苹果，它变成月亮。
  • 水面倒映着桥和亭柱，帮玩家看清藏在后面的光。

神龛里的碎片建议用柏拉图《蒂迈欧篇》的正多面体：日是正四面体（火），虹是正八面体（气），月是正二十面体（水）。集齐三片合成正十二面体，柏拉图说它是宇宙的形状，对应黎明结局。

几何校核

下面的数都用游戏里的日月轨道算过（纬度 35°，太阳赤纬 −21°，月亮赤纬 +20°）。

项目算出来的结论
圆眼登顶圆眼 7.3 m，铜环厚 0.3 m。太阳 17–17.5° 时，光穿过圆眼的净高 1.9–2.0 m，光脚落在 L3 离殿心 12.5–13 m 处可行。能通过的时间很短，正好做成"对准"的一刻。圆眼放大到 8 m，太阳 15.5–17° 都行
虹门朝向日落时太阳在方位约 242°。最高一级放在约 332°，顺时针走到那里时正好背对太阳先看到虹，再穿过拱门，成立
开场石柱正午太阳约 34°。石拱比南门高约 11 m 时，海峡约 16 m 宽；石柱的影子盖住海峡和南门的下半光在影子里显形，成立
月光下沉从光圈东缘进来的月光落到西墙的高度：月亮 10° 到 L3，19° 到 L2，31° 到 L1，48° 到水庭；每一条都从上层楼板边下面穿过成立，是夜间路线的骨架
水亭月亮约 70°（东南）时，光圈投在水面的亮区偏西北约 11 m；亭顶的影子向西北伸出约 1 mA 在亮区里，B 在亭影里，成立

待定与下一步

  • 图 3 的方位和每关的时刻是初排。原型里按"每层等时线均匀、层与层之间时间接得上"用解算器再定，窗、柱、雕像的位置跟着光反推。
  • 要你确认的：开场改成从石柱往下走进神殿；瀑布放在东侧当时间接缝；双子用卡斯托耳与波吕丢刻斯；伊莉丝浮雕放在圆眼光脚旁边。
  • 确认后重做原型：先搭新的建筑（比例、开间、柱廊、瀑布、圆眼），再从序章开始逐关做，每做完一关跑一次完整通关和光路扫查。
