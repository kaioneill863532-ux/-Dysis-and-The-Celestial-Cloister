## 一、美术资产清单

### 1. 画风方向

- 光遇风格，PBR。
- 古希腊的石头建筑，以大理石为主。
- 游戏主要依靠光影指路。光束、光斑、倒影要好看，也要让玩家一眼看得出哪里能走。
- 白天暖色：从正午的颜色一直到日落时的金红色。夜里冷色：以月光的冷白色和深蓝色为主。

### 2. 场景

细节需要等关卡调好才能确认。

**圆塔（建筑外形）**

一座多层希腊式圆殿叠成的塔。中间是上下贯通的中庭，顶上是一圈能开合的光圈式天穹。

- **楼层**：底层中央是水庭，往上是三层环形回廊，屋顶是环道。
- **水亭**：在底层水庭中央。
- **光圈形穹顶和环道**：
  - 天花板由一圈叶片组成，像相机的光圈，能向外收开。它的外沿就是一圈环形走道，分成一级级踏步，走过去时会升成阶梯或降成阶梯。
  - 一道石拱门放在最高一级上，两边各有一个小喷泉（看场景效果可以调整）。日落时，玩家可以看到一道彩虹填满拱门。
  - 穿过拱门，里面摆着一架大浑天仪，其中的太阳换成了一颗可以取下的金苹果。

**塔外**

塔外西边海上需要有一座岛（或者建筑什么的），远景剪影就行。日落时太阳沉到它后面，用来遮挡光线和光路。大小和位置等关卡搭完再确认。

### 3. 角色

**狄西斯**：日落女神，古希腊时序女神之一，玩家操控的唯一角色。

动作：

- 移动：待机、走、快走。
- 跳跃：跳、落地。
- 交互：看情况考虑要不要复杂动作，暂时就是手摸一下。
- 捧起或托起金苹果：拿起、放下。
  - 拿到金苹果以后，是一直托着，还是让金苹果漂浮在身边，看复杂程度再定。
  - 金苹果不能收起来：它带来冷暖对比，也给夜里的场景一点光，不会太暗。

### 4. 雕塑与浮雕

**托镜石像**

一尊女神像，双手托着一面铜镜，站在能转动的底座上。

| 状态 | 样子 |
|---|---|
| 日光照射时 | 把镜子举向太阳 |
| 月光照射时 | 把镜子递向前方（等夜间玩法确定再定） |
| 无光照射时 | 低头，镜子垂下 |

**伊莉丝与众神浮雕**

彩虹女神伊莉丝和其他神明宴席的浮雕。浮雕上刻着半圈彩虹（具体位置等关卡调整好），中间空着一个描金边的人形。

- 状态：平时是石头。解开谜题后，浮雕里的彩虹亮起来，一座虹桥延伸到对面。

**塞勒涅与众神浮雕**

月神塞勒涅和其他神明交流的浮雕。塞勒涅的眼睛镶着青金石。

- 状态：平时是石头。靛色的光照进她的眼睛时，眼睛亮起来。

### 5. 道具与机关

**金苹果**

一枚金子材质的苹果（后面可能会变成一个小月球）。

| 状态 | 什么时候 |
|---|---|
| 散发金光 | 台阶完全升起时 |
| 变成一个白色月亮 | 玩家把它放到底层水亭中心的浑天仪上时 |

**浑天仪**

青铜浑天仪。一道金环是太阳的轨道，一道银环是月亮的轨道，两个环上各有一颗小珠子。一共两架：

| 位置 | 太阳 | 月亮 |
|---|---|---|
| 屋顶，拱门里 | 金苹果 | 小珠子 |
| 底层，水亭中心 | 大珠子 | 一个金属小托，提示玩家把金苹果放在这里 |

**水晶棱镜**

一块水晶三棱镜，立在能被齿轮转动的底座上。

- 状态：转动；把射进来的太阳光色散成彩虹色的光束（数值等关卡调好）。

**其他道具**：等关卡确认。

### 6. 收集物

**神龛**

三个小神龛（或者像盒子、宝箱的东西），每个里面有一片旋转的立体几何形碎片。三个神龛的风格要统一，又能一眼分清日、月、虹三种属性。

- 状态：关着、打开两种状态，以及一个开启的动画。

### 7. 特效（和程序一起做）

| 特效 | 说明 |
|---|---|
| 可以踩的光束 | 窗口射进来的日光穿过水雾，看得见的光束就是可以走的路。能踩的光和不能踩的光（比如一些窗户里照进来的碎光、夜里空中的月光）要一眼看得出区别 |
| 地面光斑 | 光落在地上的亮斑，起一定的引导作用 |
| 水雾、瀑布、水沫 | 水从高处落下砸出来的效果，用来产生光路、遮蔽玩家视线等 |
| 彩虹 | 瀑布里的小彩虹；浮雕处围着玩家影子的一圈虹（等关卡确认位置）；日落时填满拱门的彩虹 |
| 虹桥 | 从伊莉丝与众神浮雕处延伸出来、能变成实体走上去的彩虹（夜里消不消失看后续效果） |
| 棱镜色散光束 | 七道细细的彩色光线，不可以踩 |
| 金苹果的光 | |
| 星空与月亮 | |
| 夜间关卡需要的特效 | 等夜间关卡定好 |
