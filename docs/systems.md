# 狄西斯的日月回廊 · 美术资产清单

> 给美术和程序看的清单：游戏里有哪些场景、角色、道具和机关，每样东西长什么样、有几种状态。先用来建模和确认画风。
>
> 尺寸、数值先不用管，都以灰盒原型为准，之后再对。玩法细节见 [设计文档](game-design.md)。

---

## 1. 画风方向

- **写实**。古希腊的石头建筑，大理石、青铜、金。
- **光是主角**。整个游戏靠光指路，光束、光斑、倒影要好看，也要一眼看得出哪里能走。
- **白天暖，夜里冷**。
  - 白天从正午的明亮，一路到日落的金红。
  - 夜里是月光的冷白和深蓝。
- **安静、空旷**。没有敌人，只有一个人和一座塔。

**建议先出的概念图**

1. 圆塔全景：建在海崖上，面朝西边海上的日落。
2. 三张色调稿：同一个角度，分别是正午、日落、子夜。
3. 狄西斯的角色设计。
4. 托镜石像的三种姿态。

## 2. 场景

### 2.1 圆塔

一座多层希腊圆殿叠成的塔。中间是上下贯通的中庭，顶上是一圈能开合的光圈天顶。

- **外观**：
  - 里面一圈实心石墙，墙上开窗；外面一圈柱廊，一共十二根柱子。
  - 西半边用暖色大理石，夕阳下会被染成金粉色；东半边用青白石材。
- **楼层**：
  - **水庭（L0）**：底层；
  - **L1、L2、L3**：三层环形回廊；
  - **顶层环道**：屋顶。
- **东侧的水钟竖井**：贴着外墙，从上到下贯通每一层，里面有水。每层有一扇铜门，朝外开一道细长的竖缝。
- **回廊断口**：
  - L1 东南断开，断口里是一道环形水渠，叫环渠；
  - L3 南边断开，断口里是一池水，叫天池。

### 2.2 窗

窗是这个游戏最重要的建筑元素：光只从窗里进来。需要这几种：

| 窗 | 样子 | 在哪 |
|---|---|---|
| 高侧窗 | 厚墙上开的普通长方窗，窗洞很深 | 各层 |
| 上下双窗 | 同一面墙上一上一下两扇窗，外面有一块能上下滑动的雪花石膏板 | L2 西南 |
| 带铜栅的窗 | 高侧窗加一道铜栅，光能进来，人进不去 | L3 南 |
| 细格窗 | 窗里有密密的窗棂，外面有铜百叶 | L2 西南（虹窗） |
| 石格窗 | 大面的石头格子窗，外面有铜百叶 | L1 东南 |
| 月窗 | 贴着地面的宽窗 | L3、L2 东北 |
| 甲门 | 通往塔外阳台的大门 | L3 西 |
| 海门 | 底层通往海边的门 | L0 东北 |

### 2.3 水庭（L0）

- **黑石镜池**：池底是黑玄武岩，水面像镜子；水面上立着几块玄武岩石墩。
- **中心小岛和小亭**：八根细柱，穹顶中间开一个圆眼，亭子正中放一只铜碗。
- **潮沟**：从海门一直通到镜池，里面有几块矮石墩（夜光石）。白天干着，夜里涨潮后灌满海水。
- **井台**：镜池边一座小石台，中间一口深井。井口刻着一只伸手捞月的猴子。
- **瀑布和水闸**：墙上的出水口、瀑布，旁边一个闸轮。

### 2.4 顶层

- **光圈天顶和环道**：
  - 天花板由一圈青铜叶片组成，像相机的光圈，能向外收开；
  - 它的外沿就是一圈环形走道，分成一级级踏步，走过去时会升成阶梯或降成阶梯。
- **接光台**：一架大的青铜浑天仪，放在最高一级上。
- **虹门**：一道石拱门，两边各有一个喷泉水盆。日落时，一道彩虹正好填满它。
- **两道铜栅**：一道挡环道，一道挡坡道口。

### 2.5 塔外

- **海崖和海**：塔建在世界西边尽头的海崖上。
- **阳台和绕塔坡道**：从 L3 的甲门出去，绕着塔外螺旋走上屋顶。
- **岩岛**：西边海上的一座岛，只是远景剪影。它朝塔的那一段山脊是平直的，日落时太阳沉到它后面。
- **天空**：从正午到日落的天空，夜里的星空和满月。

## 3. 角色

### 狄西斯（Dysis）

- 日落女神，古希腊时序女神之一。玩家操控的唯一角色。
- 长袍、面纱。
- **动作**：
  - 移动：待机、走、快走；
  - 跳跃：跳、落地；
  - 交互：转闸轮、拉拉杆、推石像底座、开龛；
  - 金苹果：举起接光，捧着走，放进铜碗；
  - 其他：拉铜链。
- 从日落接住光以后，她一直捧着发光的金苹果走完整个夜晚。

## 4. 雕塑与浮雕

| 名称 | 在哪 | 样子 | 状态 |
|---|---|---|---|
| **托镜石像** | L2 | 一尊时序女神像，双手托着一面铜镜，站在能转动的底座上 | 三种姿态：**日相**，站直、把镜子举向太阳；**月相**，把镜子递向前方；**暗相**，低头、镜子垂下。三种姿态之间要能平滑过渡 |
| **伊里斯浮雕** | L2，竖井朝中庭的那一面 | 彩虹女神伊里斯，身边刻着一整圈虹，虹的中间空着一个人形，描金边。上沿有一道细细的水帘洒下来 | 平时是石头；解开后，浮雕里的虹亮起来，变成一座虹桥 |
| **塞勒涅浮雕** | L2 北墙 | 月神塞勒涅，眼睛镶着青金石 | 平时是石头；靛色的光照进眼睛时，眼睛亮起来 |

空着的人形一定要显眼，玩家要一眼注意到"这里少了一个人"。

## 5. 道具与机关

### 5.1 关键道具

| 名称 | 样子 | 状态 |
|---|---|---|
| **金苹果** | 一枚金色的苹果，全游戏最重要的道具 | 不亮；接住阳光后发金光；最后在月光下发冷白色的光 |
| **浑天仪（大）** | 青铜浑天仪，一道金环是太阳的轨道，一道银环是月亮的轨道，环上各有一颗小珠 | 小珠跟着日月转；金苹果放在上面 |
| **浑天仪（小）** | 同款，小一些 | 放在水庭入口 |
| **水晶棱镜** | 一块铅水晶三棱镜，立在能转的底座上 | 转动；把光分成七色 |

### 5.2 机关

| 名称 | 样子 | 状态 / 动作 |
|---|---|---|
| **水闸闸轮** | 石柱上装一个青铜轮 | 转动 |
| **狮首出水口** | 墙上的青铜狮首，水从嘴里流出 | 出水 / 停水 |
| **拉杆** | 青铜拉杆 | 前后扳动 |
| **雪花石膏滑板** | 一块半透光的白色石板 | 在两扇窗之间上下滑动 |
| **铜镜** | 抛光的青铜圆镜，托在石像手上 | 跟着石像转 |
| **月锁** | 竖井门框上嵌着一弯银月，旁边一根刹杆 | 被月光照到后发亮，刹杆松开 |
| **竖井铜门** | 竖井每层一扇 | 升起 / 落下 |
| **铜链** | 从竖井顶上垂下来 | 被拉动 |
| **墙上阀门、闸轮** | 墙上的青铜小轮 | 转动 |
| **铜百叶** | 窗外的青铜百叶 | 拉开 / 落下 |
| **铜栅** | 青铜栅栏 | 升起 / 落下 |
| **光圈叶片** | 顶层天花板的一圈青铜叶片 | 向外收开 |
| **环道踏步** | 顶层环道上的一级级石阶 | 升起 / 降下 |
| **夜光石** | 潮沟里的矮石墩，平时是灰绿色 | 被金苹果照到后发青白光，慢慢暗下去 |
| **铜碗** | 小亭中心的青铜碗 | 放进金苹果 |
| **窗台伸出的石板** | 虹窗下的窗台边 | 伸出来，托着棱镜 |

### 5.3 时辰龛（隐藏收集）

三个藏在墙里的小龛，每个里面有一片碎片。三个的风格要统一，又能一眼分清日、虹、月。

| 名称 | 在哪 | 碎片 |
|---|---|---|
| 日之龛 | L3 南墙一扇高窗里 | 太阳碎片 |
| 虹之龛 | L2 虹窗下的窗台 | 彩虹碎片 |
| 月之龛 | 水庭井底 | 月亮碎片 |

每个龛都需要：关着、打开两种状态，以及一个开启的动画。

## 6. 特效

这些主要靠特效和程序，但画风要一起定：

| 特效 | 说明 |
|---|---|
| **可以踩的光束** | 窗口射进来的日光穿过水雾，看得见的光束就是路。最重要的效果 |
| **地面光斑** | 光落在地上的亮斑，开场玩家就是跟着它走的 |
| **水雾、瀑布、水沫** | 水从高处落下，砸碎成雾 |
| **彩虹** | 瀑布水沫里的小彩虹；浮雕水帘里一整圈围着自己影子的虹；日落时填满虹门的红虹 |
| **虹桥** | 一道变成实体、能走上去的彩虹 |
| **棱镜七色** | 七道细细的彩色光 |
| **月光踏片** | 夜里平静的水面上，被月光照着的一片片柔和的光，可以踩 |
| **月光大道** | 起波纹的水面上，月亮倒影拉成一条闪烁的光带，就像真实海面上的月光 |
| **井中月** | 井底水面上浮着一轮月亮 |
| **金苹果的光** | 接光时、捧着走时、在小亭里被月光重新点亮时 |
| **夜光石发光** | 青白色，慢慢暗下去 |
| **露水** | 子夜时，露天的石面上闪着细碎的光 |
| **星空、月亮** | 夜空 |

**要和程序一起定的一件事**：能踩的光和不能踩的光（比如细格窗照进来的碎光、夜里空中的月光束），一眼要看得出区别。
