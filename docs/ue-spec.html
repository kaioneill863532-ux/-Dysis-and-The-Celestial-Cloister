坐标与单位

  • 灰盒坐标：x = 东，y = 上，z = 南（−z = 北）。平面上一点写成（方位角 az、离殿心 r、高 y）：x = r·sin(az)，z = −r·cos(az)。殿心在 (0, 0, 0)，水庭地面 y = 0。
  • 换到 UE（左手系，厘米）：X = 北 = −z × 100，Y = 东 = x × 100，Z = 上 = y × 100。即 UE 的 X = r·cos(az)×100，Y = r·sin(az)×100。UE 里朝 +X 看，东在右手边。
  • 方位角 az：0° 北、90° 东、180° 南、270° 西，顺时针增加。本册所有角度都是这个方位角。
  • 时间用时角 H（度）：太阳的时角就是 H，月亮的时角是 H − 180。H = 0 是正午 12:00，每 15° 一小时。表里另附了换算的钟点。
  • 日月方向（单位向量，x 东、y 上、−z 北）：E = −cos δ·sin h，N = sin δ·cos φ − cos δ·cos h·sin φ，U = sin δ·sin φ + cos δ·cos h·cos φ。纬度 φ = 35°；太阳赤纬 δ = −21°（正午 34°），满月赤纬 +20°（最高 75°）。UE 里的方向光按这个公式每帧设置即可，本册表格可以直接对照。

时间与等时线

时间由玩家站在哪里决定。每一层是一段按方位角均匀变化的时间（等时线疏密均匀），在接缝处断开；白天顺时针时间增加，夜里逆时针时间增加。楼层之间的光路和墙里的楼梯，按玩家的高度在两端时刻之间均匀插值。沿半径的开场光和圆眼光柱、托镜像的圆台和镜光、日之龛石台、水亭和半桥上，时间不动。

光阶：从 P 跳到 R

P 在 262.5° 的窗（L3 层），光脚在 L2 342.3°；R 在 247.5° 的窗，下端钻到 L2 楼板底下，从 L2 够不着，只能从 P 上跳过去。两束光平行，在同一处 R 比 P 低 1.10 m，中心横向相距 3.20 m，光束边到边 0.80 m，算上两边余量只差 0.10 m。玩家起跳 7.6 m/s、重力 22 m/s²，往下跳 1 m 能跨 2.5 m 以上，所以这一跳很宽松。

镜光（日3 支路）为什么好走了

  • 镜子 2.6 × 1.6 m，镜子下沿和圆台顶面齐（圆台两级：0.45、0.9；半径 0.95、0.62）。反射光的下表面就从脚下开始，一步踩上去，不用跳。
  • 镜子的朝向按“下沿对准石台”解出来：仰角 23.7°，反射光坡度只有 5.8°，长 24.7 m，横穿中庭（离殿心最近 5.6 m，在雾里）。
  • 站上圆台和镜光以后时间不动，光不会摆；可踩宽 3.30 m，镜子后面还多铺了 0.6 m，接缝处不会踩空。
  • 给镜子送光的窗宽 3.0 m、高 3.2 m，保证镜面 80% 以上被照亮。
