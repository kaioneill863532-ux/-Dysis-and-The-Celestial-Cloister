# 圆殿原型 · 试玩与验证记录

## 怎样试玩

双击 `prototype/rotunda/play.html` 即可打开单文件版。若浏览器限制本地文件 WebGL，可在仓库根目录运行 `npm ci`、`npm run serve`，再访问 `http://localhost:4173/prototype/rotunda/index.html`。建议桌面端硬件加速浏览器。

WASD 行走，拖动鼠标环视，空格轻跃，E 观察、拾取和放回苹果，Q/R 转动镜像/雕像或推动月石（按住 Shift 微调），H 提示，X 回安全台，Tab 查看图纸。亮面金边表示可走日光；细光线只是光路提示。

关卡主线：D1 直射 → D2 双窗 → D3 日镜返照 → 中心天孔登顶 → 外圈绕行与苹果 → N1 女神／天鹅投影 → N2 双月石与螺旋下降 → N3 旧镜照亮下层高冠饰 → 水亭直射加返照双桥 → 中心浑天仪。三座小龛为可选，不锁主线。每段换层时保存安全台。

## 已实际验证

- 44 项纯数学、角色运动与可逆形态单元测试全部通过。
- 无浏览器 CPU 场景检查实例化完整建筑和实际 Three.js 射线遮挡，不用抽象球体替代立面和柱廊。D1、D2、D3、中心登顶均用同一 `PlayerMotor` 走到下一关的真实触发器。
- 夜间在每段入口分别初始化场景，使用同一角色运动器走过 N1 门口光桥与下楼、N2 拼合光桥与下楼、N3 旧镜光桥与下楼，水亭两段桥进入中心触发尾声。此处的“分别初始化”不等于证明完整连续通关。
- 屋顶到夜间平台的下行楼梯也用同一角色运动器走通；楼梯落在内侧环带，天鹅与壁画在外侧壁龛。调整后复查了下一层的月光直射和 N1 下行路线。
- 天鹅的程序投影被放到壁画石板的可见表面，壁画自身不接收楼梯和柱子的大块实时阴影，以免盖住需要比对的轮廓。
- N1 天鹅真实投影能达到高于阈值的吻合度；N2 固定／移动像可以同时受光并接桥；N3 旧镜能照到下层高冠饰；水亭镜子旋转到位后直射和返照同时成立。
- 夜间存档重新打开光圈；N1 楼梯入口留一跨无栏杆用于光桥接入；下降时按照目标楼层判坠落，不再错误地从楼梯中途重置。
- `npm run build` 生成约 700 KiB 离线单文件；脚本与 353 个实际用到的中文、标点字形均已内联。字体来自 Noto Serif SC，遵循随文件附带的 SIL OFL 1.1 许可。
- 用软件 WebGL Chromium 真正启动了单文件版：欢迎界面、入口、顶部、天鹅壁龛、月石层、旧镜层、水亭均有截图；键盘 W 使角色移动，中文界面清晰，浏览器脚本和控制台均无错误。单独设置关卡入口的截图只证明各场景可渲染，不代替连续通关测试。

## 尚未宣称通过

云浏览器能打开公开预览，但该环境的 WebGL 被禁用；渲染验证使用独立的软件 WebGL Chromium。仍没有硬件 GPU 帧率测试，或不使用分段初始化的“从入口到尾声”人工完整游玩证据。下一轮真人试玩应优先检查：光路边缘与建筑表面的可读性、镜面操作距离、中央穹顶展开的视觉遮挡、N1 到 N3 连续动线、读档后一切可逆状态，以及夜间水亭的末尾演出。

这份原型不会消耗 Meshy 积分，现阶段 0 积分。比例是项目内一致的幻想古典模数；具体数字与可调整边界见 `docs/proportions.md`，不是对某个古代遗址的考古复原。
