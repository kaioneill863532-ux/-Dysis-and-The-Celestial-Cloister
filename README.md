# 狄西斯的日落回廊 · Dysis and The Celestial Cloister

一款以行走、观察和空间推理为核心的 3D 解谜游戏：移动的方式决定时间，光本身就是路。

玩家扮演日落女神狄西斯，借日光登上圆殿最高处，用金苹果接住最后一缕阳光；入夜后循着月光穿过水庭，把它送到中心的小亭。
